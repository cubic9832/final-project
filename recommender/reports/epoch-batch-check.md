# 에포크·배치 재확인

## 결론

배치 256, 에포크 상한 30을 유지한다. 시드 3개에서 배치 차이는 검증 표준오차보다 작고, 고른 에포크는 4~40으로 흩어진다. 에포크 번호를 고정하지 않고, 상한 안에서 검증 top-3이 가장 높은 가중치를 쓴다.

| 항목 | 국내차 | 수입차 |
| --- | ---: | ---: |
| 유지 배치 | 256 | 256 |
| 유지 에포크 상한 | 30 | 30 |
| 배치 32·256·1024 평균 검증 top-3 차이 | 0.9%p | 0.1%p |
| 검증 표준오차 | 1.2%p | 1.6%p |
| 고른 에포크 범위 | 4~40 | 11~32 |
| 평균 검증 top-3 | 36.5~37.4% | 64.3~64.4% |
| 최다 3종 기준 | 22.9% | 47.4% |
| 균등 3장 확률 | 21.4% | 50.0% |
| 모델과 최다 3종 기준의 차이 | 약 15%p | 약 17%p |

시드 42에서 검증으로 고른 뒤 평가를 한 번 잰 값은 국내차 34.5%(검증 37.5%), 수입차 65.7%(검증 64.8%)다.

## 근거

기본 MLP만 사용했다. 은닉층 (64, 32), dropout 0.1, 학습률 0.001, 임베딩 차원 8. 바꾼 값은 배치와 에포크 상한 40이다. 시드는 42, 7, 99. 전처리는 학습 분할만 맞췄다. 선택 기준은 검증 top-3이고, 동점이면 검증 로그손실이 낮은 쪽이다.

시드 42의 검증 top-3 곡선이다. 국내차 배치 32의 37.5%는 4에포크라 5에포크 칸보다 앞이다.

시드 42에서 배치 64·128·512를 포함한 검증 top-3 범위는 국내차 36.3~37.5%, 수입차 64.1~64.8%다. 40에포크에 걸린 국내차 시드 7(배치 256·1024)의 검증 top-3은 36.5%, 36.3%로 더 이른 최고점보다 낮거나 같다.

표준오차는 국내 `sqrt(0.37 × 0.63 / 1500)` = 1.2%p, 수입 `sqrt(0.64 × 0.36 / 900)` = 1.6%p다. 1%p를 이 오차와 구분하려면 검증 약 9,000건이 필요하다. 1%p는 국내 검증 15명, 수입 검증 9명이다.

학습과 검증의 간격은 고른 시점에서 국내 학습 37~43%·검증 36~38%, 수입 학습 67~72%·검증 64~65%다.

## 앞으로의 방향성 제시

학습 설정은 배치 256, 에포크 상한 30을 유지한다. 에포크 번호는 고정하지 않고, 상한 안에서 검증 top-3이 가장 높은 가중치를 고른다. 시드 국내 1만 건·수입 6천 건에서는 배치와 에포크를 바꿔 검증 top-3을 올리려는 탐색을 하지 않는다. 그 차이는 검증 표준오차 1.2%p·1.6%p보다 작다.

이후 확인은 학습 건수를 늘렸을 때 검증 top-3 상한(국내 약 37%, 수입 약 64%)이 오르는지를 먼저 본다. 생성 10만 건은 이번 측정에 넣지 않았다. 1%p 차이를 설정 변경 근거로 쓰려면 검증이 약 9,000건은 필요하다. 은닉층, dropout, 학습률은 이번 측정에서 고정했으므로, 데이터 양을 늘린 뒤에 비교한다.
