# 같은 재무 조건에서 선호만 바꾸는 비교군 생성

`generate_preference_cohorts.py`는 기존 차량 카탈로그와 검수한 외관 평가, 새로 수집한 공식 가속 제원을 사용합니다. 차량 특성을 무작위로 만들지 않습니다. 무작위 생성 대상은 가상 사용자의 재무 조건이며 같은 seed로 재현됩니다.

## 실행

`ml/test` 작업 폴더 루트에서 실행합니다. 기존 ML 환경의 의존성을 사용하며 학습은 실행하지 않습니다. 현재 작업 폴더는 `C:/workspace/final-project/tmp/ml-test`입니다.

```powershell
$env:PYTHONPATH = 'ml'
& C:/workspace/final-project/ml/.venv/Scripts/python.exe -m tools.data.households.generate_preference_cohorts --groups 100 --seed 20261028 --output data/households/synthetic/preference-cohorts-my-run
```

다른 환경에서는 프로젝트 ML 의존성이 설치된 Python을 사용하시면 됩니다. 기존 재무 조건 생성 함수를 재사용하므로 기존 ML 환경(numpy/torch 포함)이 필요합니다. `--base`, `--luxury`, `--reviews`, `--details`로 입력 자료를 바꿀 수 있습니다. 출력 폴더가 이미 있으면 덮어쓰지 않습니다.

`--groups`는 **재무 조건의 개수**입니다. 출력 행 수가 아닙니다. 기본값은 100이며 1개 재무 조건에서 최대 12개 비교군(2개 용도 × 6개 특성), 비교군마다 3개 선호 프로필이 생성됩니다. 근거가 충분하지 않은 비교군은 건너뛰므로 정확한 개수는 보고서에 기록됩니다.

## 비교군 구성

각 비교군은 재무 조건·최소 필요 인원·후보 차량 목록을 고정합니다. 다음 중 하나의 선호만 바꿉니다.

| 비교 특성 | 세 가지 선호 | 실제 근거 |
| --- | --- | --- |
| 차체 형태 | 세단 / SUV / 쿠페 | 등록된 차체 분류 |
| 외관 비례 | 높고 직립한 / 혼합 / 낮고 스포티한 | 기존 대표 사진의 서열형 평가 |
| 윤곽 | 곡면 / 혼합 / 각진 형태 | 기존 대표 사진의 서열형 평가 |
| 가속 성능 | 낮은 / 중간 / 높은 성능 선호 대조군 | 공식 0–100km/h 시간 |
| 도심 목적 대리 지표 | 긴 / 중간 / 짧은 전장 선호 | 확인된 전장 |
| 가족 목적 대리 지표 | 적은 / 중간 / 많은 정원 선호 | 검증된 승차 정원 |

가속 성능이 낮은 쪽을 선호하는 프로필은 실험을 위한 반대 대조군입니다. 실제 소비자 분포를 나타내지 않으며, 느린 가속이 편안한 승차감이라는 의미도 아닙니다. 긴 차가 실내가 넓다거나 정원이 많으면 가족에게 항상 적합하다고 가정하지 않습니다.

각 특성에 근거가 있는 차량만 공통 후보군에 포함합니다. 미확인 값에 0점이나 중간 점수를 대입하지 않습니다. 서로 다른 모델군 2개 이상, 서로 다른 특성값 2개 이상이 없으면 비교군을 만들지 않습니다. **특성이 다른 비교군끼리는 후보 풀이 달라질 수 있으므로 단일 조건 실험으로 비교하지 않습니다.**

## 구매 가능 비교와 취향 비교

- `financial-eligible`: 기존 구매·유지비 및 최소 탑승 인원 규칙을 먼저 통과한 후보만 비교합니다. 미검증 고급 차량의 가격은 구매 가능 판정에 사용하지 않습니다. `financial_eligible=true`입니다.
- `taste-only`: 전체 조사 차량에서 확인된 특성만 비교합니다. 구매 가능 여부·필수 인원 충족을 뜻하지 않으며 `financial_eligible=null`(CSV에서는 빈칸)입니다. 가격이 미검증·누락이어도 취향 비교에는 참여할 수 있습니다.

동일한 재무 조건에서 파생된 모든 용도·특성·선호는 하나의 train/validation/test 분할에 묶습니다. 동일 재무 조건의 변형이 학습과 평가 양쪽으로 새지 않도록 합니다. 이 분할만으로 미등장 차량에 대한 일반화 성능을 평가할 수 있는 것은 아닙니다.

## 점수와 순위

- 수치 특성: `1 - abs(선호 목표값 - 차량 특성값)`.
- 차체 형태: 일치 1, 불일치 0.
- 가속 성능 변환: `clip((12 - 가속시간_초) / 10, 0, 1)` — 기존 특성 정의와 동일.
- 정원·전장 변환: 기존 `lifestyle_traits.py`의 정의를 재사용.
- 동점은 같은 순위입니다. 차량 ID 정렬은 파일의 순서를 고정할 뿐 우열이 아닙니다.

이 점수는 **명시한 규칙으로 만든 합성 정답**입니다. 실제 사용자 선택이나 현재 ML 모델의 예측이 아닙니다. 해당 규칙을 잘 학습하는지 검증하는 용도로 사용합니다. 모든 프로필이 다른 차량을 선택하게 임의로 정답을 뒤집지 않습니다.

새 상세 제원에서 가속 값을 가져올 때 ID·브랜드·모델·트림·연식을 모두 대조합니다. 단위가 초로 명확하고 값이 하나인 항목만 사용하며 충돌 항목은 제외합니다. 스포츠 크로노 패키지 등 제원 측정 조건과 출처를 특성 스냅샷에 보존합니다. 서로 다른 제조사의 공개 측정 조건은 같다고 보장하지 않습니다. 상세 제원 중 좌석·가격·전장은 이번 코드에서 기존 학습 카탈로그에 덮어쓰지 않습니다.

## 출력

| 파일 | 내용 |
| --- | --- |
| `catalog.json` | 사용한 전체 차량 및 원래 검증 상태 |
| `vehicle_traits.json` | 비교 특성값과 원자료·출처·조건 |
| `comparisons.jsonl` | 한 줄에 고정 재무 조건·공통 후보군·세 프로필의 전체 순위 |
| `rankings.csv` | 한 줄에 비교군 × 선호 프로필 × 차량의 점수와 순위 |
| `generation_report.json` | 생성 설정·행 수·특성 보유율·건너뛴 비교군·원본 해시·한계 |
| `saved_data_audit.json` | 저장 파일을 다시 읽어 후보 적격·순위·동점·분할·CSV 연결을 재검증한 결과 |

CSV의 주요 컬럼은 `comparison_id, group_id, split, task, axis, target, monthly_income, monthly_expenses, liquid_assets, minimum_seats, vehicle_id, brand, model, trim, rank, policy_score, trait_value, financial_eligible, evidence_source, label_origin`입니다. 금액은 원 단위이고 CSV는 Excel에서 열 수 있는 UTF-8 BOM 형식입니다. 공통 실험 조건 전체는 JSONL에 보존합니다.

기존 100만 건 합성 데이터와 모델은 변경하지 않습니다. 이 출력은 목록 순위 비교용 새 스키마이므로 기존 2대 선택형 trainer에 바로 넣을 수 없습니다. 재학습을 원하면 이 스키마에 맞는 로더·손실 함수 또는 쌍별 변환을 추가해야 합니다.
