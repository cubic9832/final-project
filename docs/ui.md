# UI 기준

## 컬러 시스템

- 딥 네이비 `#203960`를 Primary 컬러로 사용하여 브랜드의 신뢰성과 전문성을 강조한다.
- 민트 그린 `#54B19D`는 핵심 CTA 버튼, 전환·성공 맥락의 금액, 성공 상태 등 핵심 액션에 제한적으로 사용한다. 핵심 수치와 금액의 기본 색상은 네이비로 한다.
- 블루 `#3F8AE2`는 링크, 활성 상태, 보조 강조 요소에 사용한다.

## 배경 및 레이아웃

- 전체 페이지의 기본 배경은 라이트 그레이 `#F7F8FB`로 한다.
- 콘텐츠는 화이트 `#FFFFFF` 카드로 구분한다.
- 카드에는 12~16px의 둥근 모서리, 얇은 테두리 `#E2E8F0`, 24px의 내부 여백을 적용한다.

## 타이포그래피

- 제목과 핵심 수치는 기본적으로 네이비 계열의 굵은 글씨로 강조한다. 전환·성공 맥락의 금액에 한해 컬러 시스템의 민트 강조를 적용한다.
- 본문은 짙은 회색, 설명과 보조 텍스트는 채도가 낮은 블루 그레이를 사용한다.
- 명확한 폰트 크기와 굵기 계층을 유지하여 정보의 우선순위를 전달한다.

## 버튼 및 인터랙션

- Primary 버튼은 네이비, 핵심 전환을 유도하는 CTA 버튼은 민트 그린으로 구성한다.
- 버튼과 입력 필드는 일관된 높이 40~48px와 둥근 모서리 8~12px를 적용한다.
- Hover, Focus, Disabled, Selected 상태를 시각적으로 구분한다.
- 버튼·입력·선택·체크박스의 크기와 비활성 상태를 일관되게 제공하고, 비동기 동작을 실행하는 컨트롤에는 로딩 상태를 제공한다.

## 폼 제출 및 화면 상태

- 제출 전에 필수값을 검증하고, 필드 오류는 해당 필드에 인라인으로 표시한다. 서버에서 반환한 필드 검증 오류도 해당 필드에 연결한다.
- 제출 중에는 제출 버튼을 비활성화하고 제출 처리에서도 중복 요청을 방지한다. 실패하면 입력값을 유지하고 다시 제출할 수 있게 한다.
- 화면의 로딩·빈 목록·오류 상태를 구분한다. 빈 목록은 정상 조회 결과로 안내하고, 재시도 가능한 오류에는 재시도를 제공한다.
- API 요청의 로딩·성공·실패를 처리하고 사용자에게 결과를 안내한다. 자세한 API 설계는 [REST API 기준](api.md)을 따른다.

## 오버레이 및 작업 피드백

| 구분 | 공통 규칙 |
| --- | --- |
| 모달 | 사용자 결정이 필요한 작업에 사용한다. 배경을 어둡게 하고 배경 조작을 차단한다. 일반 모달은 바깥 클릭·Esc로 닫고, 위험한 작업은 명시적인 버튼으로만 닫는다. |
| 편집 모달 | 저장하지 않은 변경이 있으면 닫기 전에 같은 모달 내부에서 변경 폐기를 확인한다. 별도 확인 모달을 중첩하지 않는다. 내부 선택은 인라인으로 펼친다. |
| 토스트 | 짧은 결과·비동기 실패 안내에 사용하며 입력을 차단하지 않는다. 4초 후 닫되 호버·포커스 중에는 타이머를 정지한다. 수동 닫기를 지원한다. |
| 메뉴·팝오버 | 클릭·탭으로 열고, 같은 트리거 재클릭·바깥 클릭·Esc로 닫는다. 선택한 작업이 모달을 열면 메뉴부터 닫는다. |
| 툴팁 | 호버·키보드 포커스로 짧은 설명을 표시한다. 아이콘 버튼의 접근성 이름을 함께 제공한다. |
| 작업 피드백 | 저장 등 비동기 작업은 진행 상태와 완료 결과를 안내한다. 화면 안에서 해결해야 하는 검증·오류는 해당 위치에 인라인으로 표시한다. |

- 모달 닫기는 위험 작업·미저장 변경 규칙을 일반 닫기 규칙보다 우선 적용한다. 위험 작업은 바깥 클릭·Esc로 닫지 않으며, 미저장 변경이 있으면 명시적 닫기 버튼을 포함한 모든 닫기 시도에서 변경 폐기 확인을 거친다. 폐기를 취소하면 모달과 변경을 유지하고, 확인하면 닫는다.
- 모달이 열리면 내부로 포커스를 이동하고 열린 동안 키보드 포커스를 내부에 유지한다.
- 모달·메뉴가 닫히면 열었던 트리거로 포커스를 복귀한다. 트리거가 사라졌다면 다음으로 적절한 조작 요소에 복귀한다. 메뉴에서 모달을 여는 경우에는 새 모달로 포커스를 이동한다.

## 컴포넌트 일관성

- 카드, 입력 필드, 선택 버튼, 요약 패널 등 반복되는 UI 요소에 동일한 컬러·간격·테두리 규칙을 적용한다.
- 8px 기반 Spacing System을 사용한다.
- 색상·간격·글꼴·반경은 공통 테마 토큰으로 정의하고 컴포넌트에서 재사용한다.
- 과도한 그림자나 장식을 배제하고 정보 전달과 사용자의 의사결정에 집중한다.

## 디자인 원칙

- 미니멀하고 신뢰감 있는 금융·자동차 서비스 디자인을 지향한다.
- 핵심 정보와 금액을 명확하게 강조한다.
- 충분한 여백과 높은 텍스트 대비를 유지하여 가독성, 접근성, 반응형 사용성을 확보한다.
