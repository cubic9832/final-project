# 관리자 대시보드 UI

`/admin`에서 기존 서비스 헤더와 공통 테마를 유지한 사이드바 운영형 화면을 제공한다. 현재는 관리 API를 호출하지 않는 예시 UI이며 실제 차량·회원·모델 정보를 변경하지 않는다.

| 메뉴 | 주소 | 화면 동작 |
| --- | --- | --- |
| 운영 현황 | `/admin?tab=overview` | 요약 카드, 관리 바로가기, 서비스 상태, 최근 이력 |
| 차량 관리 | `/admin?tab=vehicles` | 차명·브랜드 검색, 공개 상태 필터, 검수 상세 |
| 추천 관리 | `/admin?tab=recommendations` | 4개 예시 라벨 선택, 이미지·주요 정보·추천 문구 미리보기 |
| 회원 관리 | `/admin?tab=members` | 가상 회원 검색, 권한 필터, 회원·로그인 잠금 상태 상세 |
| 모델 관리 | `/admin?tab=models` | 예시 모델 버전, Top-1·Top-3·Macro F1 비교, 적용 이력 |
| 운영 로그 | `/admin?tab=logs` | 유형·검색어 필터, 표시된 예시 로그의 CSV 다운로드 |

추천 문구는 현재 탭 안에서만 미리보기에 적용하며 다른 메뉴로 이동하거나 새로고침하면 초기화된다. 화면 새로고침 버튼은 표시 시각만 갱신한다. 관리자 권한 검사와 관리 API 연동은 이번 UI 작업에 포함하지 않는다.

1024px 이하에서는 콘텐츠 카드를 한 열로, 768px 이하에서는 메뉴를 상단 격자로 바꾸고, 480px 이하에서는 입력·메뉴·선택 카드 간격을 좁은 화면에 맞춘다. 표는 필요한 경우 표 영역 안에서만 가로 스크롤한다.
