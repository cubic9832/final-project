# 테스트 기준

## 유지할 테스트

- 핵심 비즈니스 로직 테스트와 주요 사용자 흐름의 E2E 테스트만 유지한다.
- 핵심 비즈니스 로직을 검증하는 데 필요한 API 계약·DB 연동 등의 통합·계약 테스트도 핵심 로직 테스트에 포함하여 허용한다. 테스트 종류보다 실제 오류를 발견하는 검증 목적을 기준으로 판단한다.
- 금액 계산, 조건별 의사결정, 상태 전이 등 실제 오류를 발견할 수 있는 동작을 검증한다.
- 핵심 로직은 정상·경계·실패 사례를 검증하고, E2E는 사용자 관점에서 주요 흐름의 결과를 검증한다.

## 추가하지 않거나 제거할 테스트

- 테스트 개수나 커버리지 수치를 채우기 위한 허수 테스트는 추가하지 않으며 발견하면 제거한다.
- 상수·단순 대입 비교와 구현을 그대로 반복하는 검증은 추가하지 않으며 발견하면 제거한다.
- 비교 assertion을 사용한다는 이유만으로 제거하지 않는다. 중요한 비즈니스 동작이나 사용자 결과를 검증하는 비교는 유지한다.
