# 데이터 요청 초안

문의용 초안이며 발송하지 않았다. 목적은 국내 신차 구매자의 특성과 실제 선택 모델의 관계를 학습하는 비영리 프로젝트다.

## 컨슈머인사이트 무료 다운로드 확인

2024년 자동차기획조사 초기품질 평가 원자료와 코드북을 이용하려고 합니다. 이용약관 동의 후 다운로드를 실행하면 파일이 수신되지 않고 상세 페이지로 돌아옵니다. 정상 다운로드 방법 또는 파일 제공 경로를 안내 부탁드립니다. 구체적인 구매 모델명/모델 코드와 국산·수입 구분, 신차 구매 여부, 표본 가중치가 공개 자료에 포함되는지도 확인하고 싶습니다.

## CarCharts 자료 요청

국내 브랜드 승용 신차의 개인 신규 등록 자료를 활용하려고 합니다. 최근 12개월에 대해 등록 월×성별×연령대×모델의 공동 집계 건수를 CSV 또는 XLSX로 받을 수 있는지 확인 부탁드립니다. 법인·렌트 제외, 등록 명의자 기준, 모델/세대 코드, 모델별 등급, 소수 셀 처리 및 미상 성별·연령 처리 기준도 필요합니다. 프로젝트 연구·학습 활용, 결과 공개, 자료 재배포 가능 범위와 비용을 알려주시기 바랍니다.

## 컨슈머인사이트 실제 구매자 맞춤 자료 요청

구매 의향 조사 대신 실제 국산 신차 구매자의 응답자별 자료를 요청합니다. 익명 ID, 성별·연령·지역·가족 구성, 구매 당시 소득(개인/가구 및 세전/실수령 구분), 실제 구매 모델·세대·연료·구매 연월을 동일 응답자에 연결한 자료가 필요합니다. 자산·부채·생활 소비 항목이 같은 응답자에 연결되어 있는지도 확인 부탁드립니다. 변수 목록과 코드북, 표본 수·모델별 사례 수·가중치, 신차·국산 필터, 학습 및 결과 공개 조건, 무료 학술 제공 가능 여부 또는 견적을 요청합니다.
