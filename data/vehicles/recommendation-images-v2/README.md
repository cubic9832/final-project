# 추천 차량 이미지

`ml/test` 추천 카탈로그 281개 사양, 84개 브랜드·모델 조합의 이미지 연결 자료입니다.

- 기존 이미지 20장을 보존하고 새 이미지 59장을 추가했습니다. 총 79장으로 84개 모델을 표시합니다.
- 제조사의 투명 배경 원본 41장은 픽셀을 수정하지 않고 복사했습니다. 배경 편집이 필요한 18장은 공식 사진을 참조해 imagegen으로 배경을 제거했습니다.
- 전면 사선에서 차량 전체가 보이는 사진을 선택했습니다. 전기차·GT·왜건·블랙 등 외형이 다른 모델은 별도 사진을 연결합니다. 동일 차체의 일부 하이브리드는 대표 사진을 공유합니다.
- 기존 3:2 카드와 맞춰 차량의 불투명 영역을 카드 폭 85%, 높이 65% 안에 표시합니다. 투명 원본의 캔버스 크기가 달라도 CSS 배치로 정렬하며 원본을 재가공하지 않습니다.
- 모델 대표 이미지이므로 실제 연식·엔진·트림·색상·휠 옵션과 차이가 있을 수 있습니다. 화면에도 기존 예시 이미지 안내를 유지합니다.

## 파일

- `manifest.json`: 최종 모델별 이미지, 공식 출처 URL, 원본·배포 파일 해시, 처리 방식, 배치 기준.
- `reviewed-sources.json`: 최종 채택한 공식 원본 59장. 출처를 확인한 사진만 재수집합니다.
- `edited-images.json`: 배경 편집본 18장의 파일과 생성 식별자.
- `sources/`, `pages/`, 나머지 수집 JSON: 공식 원본 및 검토 과정의 수집 기록. 최종 채택 여부는 `manifest.json` 기준입니다.
- `review.html`: 전체 84개 모델을 모아 보는 로컬 검수 문서. 저장소 폴더 구조를 유지한 채 브라우저에서 열 수 있습니다.
- `recommendation-preview.png`: 실제 재무 진단에서 전기차 추천을 실행한 화면.

## 재생성

저장소 루트에서 실행합니다. 원본 수집에는 네트워크가 필요하며 공식 사이트 이미지가 변경되면 검토 후 반영해야 합니다. 배경 편집본은 별도로 보존합니다.

```powershell
python tools/data/vehicles/collect_recommendation_images.py
python tools/data/vehicles/build_recommendation_images.py
```
