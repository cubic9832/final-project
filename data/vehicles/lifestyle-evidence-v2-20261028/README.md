# 차량 취향 특성의 근거와 평가 기준

`reviews.json`은 사진 검수 12개 모델군과 공식 가속 제원 2개 모델의 근거다.
차량 특성을 난수로 생성하지 않는다. 사용자 선호·중요도·확률적 선택만 합성한다.

## 사진 검수

`data/vehicles/official-image-review/contact-sheet.jpg`와 연결된 공식 원본 이미지에서
K5, K8, 니로, 레이, 모닝, 셀토스, 스포티지, 아반떼, 쏘나타, 코나, 팰리세이드, Model Y의
외관 비례와 각진 정도를 Codex가 시각 검토했다. 사진 파일 SHA-256, 공식 출처, 관찰 이유를
각 항목에 남겼으며 생성할 때 이미지 해시를 검증한다. AI로 배경 제거한 이미지는 사용하지 않았다.

평가값은 0 / 0.5 / 1의 서열 척도다. 정밀 측정값이나 고객 선호 조사 결과가 아니다.

| 항목 | 0 | 0.5 | 1 |
|---|---|---|---|
| 외관의 스포티한 인상 | 높고 직립한 박스·해치형 비례 | 혼합·중간 비례 | 낮고 길며 뒤로 흐르는 루프 비례 |
| 외관의 각진 정도 | 둥근 윤곽·곡면 중심 | 직선과 곡선 혼합 | 각진 윤곽·면·캐릭터 라인 중심 |

사진은 대표 모델군의 인상을 나타낸다. 모든 연식·세대·트림의 일치를 인증하지 않으며,
휠·색상·촬영 각도에 영향을 받는다. 해당 한계는 개별 근거에도 기록했다.
ES는 사진과 기존 데이터의 세대 차이 가능성 때문에 제외했다.
별도로 확인하지 않은 하이브리드·전기차·스포츠 파생형에 이름 유사도만으로 태그를 복사하지 않는다.
`years`나 `trims`가 지정된 평가는 정확히 일치할 때만 적용한다.

실내 구성, 승차감, 정숙성, 운전 재미는 외관 사진에서 추론하지 않는다.
확보한 검수 자료가 없어 실내·승차감 값은 null이며 정답 계산에서 제외한다.

## 제원과 사용 목적

- 정원: 카탈로그의 `official-source-verified` 상태와 정원 출처가 함께 있을 때만 사용한다.
- 소형 선호: 전장과 전장 출처가 있을 때만 사용한다. 전장이 크다고 적재 공간이 넓다는 뜻은 아니다.
- 가속 성능: Lamborghini [Temerario](https://www.lamborghini.com/en-en/models/temerario),
  [Revuelto](https://www.lamborghini.com/en-en/models/revuelto-models/revuelto)의 공식 글로벌 제원을 확인했다.
  국내 판매 상태·가격·연비를 확인했다는 뜻은 아니다. 운전 재미나 승차감으로 치환하지 않는다.
- Ferrari 12Cilindri Spider의 차체 분류는 [제조사 공개 자료](https://www.ferrari.com/content/dam/ferrari-fcom/old/pdf/CS_Ferrari_12Cilindri_Spider_def_gbr.pdf)를 근거로 연결했다.
  국내 가격이나 주문 가능 상태는 미확인으로 보존한다.

용도는 선언한 단순 선호 규칙이다. 출퇴근은 작은 외부 크기, 가족은 확인된 정원,
주말 주행은 가속 성능을 보조 지표로 사용한다. 캠핑은 적재량·적재 구조 자료가 없고
업무는 승차감 근거가 없어 용도 점수를 부여하지 않는다. 다른 알려진 취향 항목은 사용할 수 있다.
정숙성·적재량·견인·출력·중량 자료를 확보하면 각각 별도 검수 특성으로 추가해야 한다.

미확인 항목은 중간점수로 채우지 않는다. 비교 중 한 차량이라도 해당 근거가 없으면
두 차량에서 그 항목과 가중치를 함께 마스킹한다. 근거가 풍부한 차량을 보상하거나
자료가 없는 차량을 벌점 처리하지 않기 위한 규칙이다.
