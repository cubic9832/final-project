# 가격·트림·옵션·구매자금을 보정한 합성 차량 보유자

이 버전을 이전 `owner-population`의 후속 학습용 데이터로 사용한다. 만 20~59세 10,000명, 프로필 ID·기본 인적 특성과 기존 학습/검증/평가 구분을 유지한다. 전원이 이미 차량을 구매한 가상 보유자다. 구매보류나 차량 미배정 행은 없다. 기존 모델을 무조건 유지하지 않고 재무 조건에 맞는 트림·사양으로 다시 선택한다. 이전 원본은 그대로 보관한다.

## CSV

- `차량보유자_재무특성_보정학습데이터.csv`: 사람의 특성과 보유 모델 라벨. 기존 소비·현재 개인 소득·자산은 보존하되 비현실적인 기존 대출 상환 부담을 보정하고 차량 대출·상환액을 합산한다. 저축과 월 잔여액·순자산을 다시 계산한다.
- `보유차량_트림옵션_구매자금내역.csv`: 프로필별 실제 선택 사양의 연식 표기·파워트레인·트림·옵션·가격·구매 자금·월 원금/이자·공식 출처. 프로필 ID로 연결한다. 기존 모델과 변경 모델도 비교할 수 있다.
- `차량별_보유자특성_보정요약.csv`: 보정된 모델별 인원·연령·소득·현금·소비·월 상환액 분포. 실제 구매자 통계가 아니다.

금액은 원이며 금리 0.065는 연 6.5%다. CSV는 UTF-8 BOM이다. 같은 프로필 ID는 이번 버전과 바로 이전 `owner-population` 사이에서 동일 가상 인물에 대응한다. 더 오래된 `ownership`/`generated`와는 연결하지 않는다.

## 가격과 옵션 근거

기존 공식 가격표 스냅샷에서 14개 모델의 가격이 있는 123개 트림·파워트레인 사양을 사용한다. 최신 실거래가나 할인 후 견적이 아니라 `normalized-vehicle-details.json`의 공식 표시 가격 자동 추출값이며, 세제 적용 기준은 원본 사양의 price_basis를 따른다. 트림별 기본 품목은 해당 트림 가격에 포함된 것으로 처리한다. 출고 색상·탁송·개별 할인 등은 모델링하지 않았다.

별도로 현대자동차 공식 쏘나타·아반떼 가격표 1페이지를 내려받아 시각 검토했다. 지원하는 유료 옵션은 상위 `purchase_refinement_config.json`의 정확한 모델/엔진/트림 키와 일치하는 경우에만 적용한다.

- 쏘나타 가솔린 1.6 터보 Premium: 내비Ⅰ 140만원, 파킹Ⅰ 98만원(내비Ⅰ 필수), 스마트센스Ⅰ 45만원, 하이패스 20만원.
- 쏘나타 같은 엔진 S: 파킹Ⅱ 98만원, HUD 70만원(파킹Ⅱ 필수).
- 아반떼 가솔린 2.0 Modern: 슬림 디스플레이 35만원, 컨비니언스Ⅰ 65만원, 스마트센스Ⅰ 96만원.
- 아반떼 같은 엔진 Premium: 선루프 90만원, 커넥트/슬림 디스플레이 묶음 83만원.

검토 범위 밖의 옵션은 추측하지 않는다. 나머지 사양은 추가 유료 옵션을 선택하지 않는다. `옵션수집범위`에 전체 옵션 미수집 여부를 표시한다. 이것이 그 차에 선택 가능한 옵션이 없다는 의미는 아니다. 공식 가격표 전체 옵션 카탈로그를 완성한 데이터도 아니다. 휠·구동방식·좌석 변경 옵션은 이번 선택 목록에서 제외했다. 확인한 페이지의 표에서 들여쓴 선행 조건을 반영해 조건부 옵션을 단독 선택하지 않는다.

## 재무 정합성 가정

1. 기존 합성 담보·신용대출의 월 상환액은 현재 개인 월 실수령의 25% 이내로 보정한다. 초과 사례의 잔액도 같은 비율로 축소하고 보정 전·후 값을 구매 내역에 남긴다. 실제 대출 재조정 사실이 아니라 이전 더미의 과도한 부채를 고치는 생성 규칙이다.
2. 구매 당시 개인 연간 세전소득은 현재의 0.95~1.2배를 가정하고 최소 2,400만원으로 설정한다. 현재 저소득·비취업자의 경우 구매 당시 취업/소득과 지금의 소득이 다를 수 있음을 표현한 가정이다. 실제 소득 변화를 관측한 것이 아니다. 82% 간이 실수령 비율은 세금 계산식이 아니다.
3. 사회 초년생은 옵션 포함 가격을 구매 당시 연소득의 0.9배+현금 일부 이내, 동시에 4,000만원 이하로 제한한다. 경력자는 연소득 1.2배+현금 일부 이내다. 이는 법정 기준이나 구매 자격이 아닌 더미의 과도한 배정을 줄이는 설정이다.
4. 본인 자금 상한은 구매 당시 연소득의 20%×가정 저축 연수(경력+1, 최대 8년)+현재 현금의 50%다. 구매 직전 현금=구매 후 현재 현금+본인 지출로 연결한다. 별도의 과거 자산 축적 시계열을 재현하지는 않는다.
5. 가족 지원은 10% 확률로 가정하되 총 구매 비용의 20%와 초년생 500만원/기타 1,000만원 중 더 작은 한도 이내다. 지원 여부가 고가 차량 제한을 우회하지 않는다. 지원 확률은 실제 조사값이 아니다.
6. 등록비는 옵션 포함 가격의 7% 적립액을 가정한다. 경차·친환경차 감면 등을 계산한 법정 취득세가 아니며 보험료·탁송료도 총 구매 비용에 포함하지 않는다.
7. 차량 할부는 차량 가격의 최대 80%, 연 6.5%, 60개월 원리금균등으로 설정한다. 월 차량 상환액은 구매 당시 실수령의 20%, 기존 상환과 합계는 45% 이내다. 초과 후보는 배정하지 않는다.
8. 기본가격+옵션가격+등록비=본인자금+가족지원+차량할부원금을 원 단위로 맞춘다. 차량 할부를 현재 부채와 월 상환액에 더하고 자산·저축·잔여액을 재계산한다. 개인 순자산은 차량 자산가치를 제외하므로 차량 할부만큼 낮아질 수 있다.

현재 재무 상태는 동일 가격 기준으로 최근 출고한 직후의 합성 스냅샷이다. 과거 연월의 신차 가격·모델 출시 시점·수년간 할부 상환 이력을 만든 것으로 해석하지 않는다. 구매 당시 소득과 현재 소득의 차이 때문에 현재 월 적자 사례는 남길 수 있으며 이를 차량 미보유로 바꾸지 않는다. 평균 생활 소비에 차량 유지비 항목을 별도로 산출·대조하지 않았으므로 유지비 정밀 시뮬레이션용 자료는 아니다.

## 학습 입력 구분

보정 학습 CSV에서 보유차량 라벨코드/모델을 정답으로 사용하고 브랜드·차체·차급 등 다른 정답 표현과 식별자·관리 열은 입력에서 제외한다. 구매 내역 CSV의 차량 가격·트림·옵션·사양 ID·차량별 대출 등은 정답을 노출할 수 있으므로 특성 유사도 모델의 입력으로 그대로 합치지 않는다. 집계 요약은 설명용이며 학습 프로토타입은 학습 구간만으로 다시 계산한다. 모델별 사례 수를 균등하게 강제하지 않았으므로 변경된 라벨 분포를 확인한다.

## 재현

`python -m tools.data.households.refine_owner_purchases` 실행 후 bundled Node로 `tools/data/csv/exportFundedOwnerCsv.mjs`를 실행한다. 주요 비용·한도·옵션은 상위 설정 파일에 기록한다. 입력 해시·재현성·정합성 결과는 `validation-report.json`에 보관한다. 이번에도 실제 차량 보유 경향은 검증하지 않았으며 학습되는 관계는 가상 생성 규칙이다.
