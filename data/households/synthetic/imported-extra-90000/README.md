# 수입차 보유자 추가 90,000건

기존 국내 데이터 및 수입차 6,000건을 유지하고 같은 형식·단위·생성 조건으로 새 인물 90,000명을 별도 생성한다. Model Y, E-Class, BMW 5시리즈, 렉서스 ES, BMW X3, 볼보 XC60에 각 15,000명을 배정한다. 기존 수입차 6,000건과 합치면 96,000건이다. 합본을 만들거나 기존 파일에 덧쓰지 않는다.

## 출력과 식별자

- `수입차_보유자_추가90000_학습데이터.csv`: 90,000행, 기존과 동일한 37열.
- `수입차_추가90000_트림옵션_구매자금내역.csv`: 90,000행, 기존과 동일한 34열.
- `수입차_추가90000_보유자특성_요약.csv`: 이번 추가본만 집계한 모델별 6행, 기존과 동일한 14열.

프로필 ID는 **P106001~P196000**으로 국내 추가본의 P106000 뒤에서 시작한다. 차량 라벨 OWN015~OWN020과 사양 IMP-C번호는 같은 수입차를 뜻하므로 기존 목록을 재사용한다. 금액은 원, 금리는 비율, 인코딩은 UTF-8 BOM이다. 만 20~59세이며 전원 이미 구매한 차량을 보유한 합성 인물이다. 학습 63,000명·검증 13,500명·평가 13,500명이다.

## 유지한 조건

기존 `imported-owners/catalog.json`의 18개 사양과 가격 스냅샷을 사용한다. 가격 갱신이나 모델·옵션 수집 범위 확대는 하지 않았다. 가격 범위는 4,999만~9,120만원이며, 테슬라는 공식 주문 페이지 접근 제한으로 기존에 확인한 국내 보조 출처를 그대로 사용한다. ES는 ES 350h이며 ES 300h 가격과 혼합하지 않는다. 트림 기본 장비는 가격에 포함하며 추가 유료 옵션은 모두 미선택이다.

기존 수입차 집단의 가상 소득·자산 분포와 국내 보정본의 구매 자금·할부 규칙을 재사용한다. 연 6.5%·60개월, 가정 등록비 7%, 가족 지원 확률·상한, 월 차량 상환 20%/전체 상환 45% 조건을 유지한다. 사회 초년생 차량 가격 4,000만원 한도보다 모든 후보가 비싸므로 이 추가본에도 사회 초년생은 없다. 실제 수입차 시장에 사회 초년생이 없다는 뜻이 아니다. 상세 한계·가격 출처는 기존 `imported-owners/README.md`를 따른다.

## 독립 생성과 검증

배치 시드는 20261022다. 1,500명씩 60회 생성하며 각 묶음의 시드는 배치 시드+묶음 순번×10,000이다. 각 묶음에서 모델당 250명을 확보할 때까지 기존 생성 규칙에 맞는 후보를 추린다. 각 묶음을 두 번 실행하여 결과가 같은지 확인한다. CSV의 난수_시드는 전체 배치 재현용 시드를 기록한다.

기존과 추가본 내부에서 나이·성별·연소득·현금·가구원 조합의 중복을 검사한다. 기존 파일 해시 불변, ID 비충돌·연속성, 동일 컬럼 구조, 실제 사양 가격 연결, 구매 자금 합계, 자산·부채·월 상환 회계식, 모델별 사례 수와 구간 분할을 검증한다. 결과는 `validation-report.json`과 `csv-validation.json`에 기록한다.

`python -m tools.data.households.generate_extra_imported` 실행 후 bundled Node로 `tools/data/csv/exportExtraImportedCsv.mjs`를 실행한다. 기존 생성기와 설정 파일을 읽으므로 재현 시 해당 파일들도 함께 보존한다.

모델별 동일 인원은 학습용 사례 확보 설정이며 실제 시장 점유율이 아니다. 가상 패턴의 표본 수를 늘린 것이므로 실제 구매 경향·추천 정확도의 근거가 늘어난 것으로 해석하지 않는다. 입력에서 차량 라벨의 다른 표현과 식별자·관리 컬럼·가격/트림 등 정답 노출 정보는 제외한다.
