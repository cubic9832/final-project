# 현재 UI 기반 합성 비교 선택 데이터

사용자 10,000명, 비교 선택 99,442건. 39개 기존 생활·재무 사례 주변에서 재무를 변형하되
현재 UI의 선호·중요도·상관없음 상태를 다시 표본 추출하고 정답을 새로 생성했다.
사용자별 최대 10쌍이며 필수 인원이 많아 후보가 적으면 가능한 비교 수만 보존한다.

- 학습 7,039명·69,975쌍 / 검증 1,453명·14,428쌍 / 평가 1,508명·15,039쌍
- 96개 모델·308개 사양. 분할별 모델 최소 비교 횟수와 전체 사양 노출 검사 통과.
- 재무 그룹 해시로 분할하고, 동일 재무 그룹의 중복·분할 누수 검사 통과.
- 학습·추론의 38개 특징이 전체 저장 후보에서 정확히 일치하는지 검증.
- 독립 Decimal 현금 구매·12개월 부족액 보전 검사와 필수 좌석 검사 통과.
- 윤곽·가속·연료·크기의 상관없음, 인원 제한 없음, 각 중요도 1/3/5를 포함한다.
- 차체 형태·브랜드·특정 모델 호감·외관 비례는 선택 선호에서 제외한다.
- 연간 주행거리는 UI와 동일하게 15,000km. 충전은 전기 선호일 때만 알고 있다고 취급한다.
- 중요도는 단일 취향에서도 비용 등 다른 기준에 대한 상대 효과가 바뀌도록 정답 생성에 적용한다.
- 차량 특징은 별도 동결한 vehicle_traits.json을 사용한다. 실제 고객 조사 데이터가 아니다.

원본: `tools/data/households/generate_ui_scenario_population.py`.
설정·원본 해시·분할별 파일 해시는 configuration.json과 manifest.json,
전체 감사 결과는 validation_report.json에 기록한다.
profiles JSONL은 관측 입력, choices JSONL의 확률·추첨값은 감사 전용이다.
정답·확률·추첨값·사용자 ID·분할·원본 사례 ID는 모델 특징에 들어가지 않는다.
