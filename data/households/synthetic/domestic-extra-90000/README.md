# 국내 차량 보유자 추가 90,000건

기존 국내 보정본 10,000건과 수입차 6,000건을 변경하지 않고 새로 생성한 국내 차량 보유자 데이터다. 기존 국내 보정본과 합치면 국내 데이터는 총 100,000건이다. 기존 파일에 덧쓰거나 합본 파일을 생성하지 않았다.

## 출력

- `국내차_보유자_추가90000_학습데이터.csv`: 신규 인물 90,000명, 기존과 동일한 37개 한국어 컬럼.
- `국내차_추가90000_트림옵션_구매자금내역.csv`: 각 인물에 연결된 트림·옵션·본인 자금·가족 지원·할부 내역, 기존과 동일한 34개 컬럼.
- `국내차_추가90000_보유자특성_요약.csv`: 추가본 90,000명만 대상으로 집계한 14개 모델의 요약, 기존과 동일한 14개 컬럼.

프로필 ID는 **P016001~P106000**이다. 국내 기존 P000001~P010000, 수입차 P010001~P016000과 겹치지 않는다. 국내 모델 라벨 OWN001~OWN014와 사양 ID C번호는 같은 차량을 뜻하므로 기존 국내 목록을 재사용한다. 서로 다른 사람에게 같은 차량 라벨이 붙는 것은 정상이다. 금액은 원 단위이고 금리는 비율이다.

## 생성 규칙

생성 시드 20261021을 사용해 기존 행을 복제하지 않고 새 프로필을 만든다. 기존 나이·성별·연소득·현금·가구원 조합과 추가본 내부의 같은 조합이 없는지 확인한다. 이는 모든 현실 인물이 고유하다는 주장이 아니라 더미 중복 방지 검사다.

만 20~59세, 전원 차량 보유, 14개 국내 모델, 공식 가격표 스냅샷의 123개 트림·파워트레인, 기존에 검토한 일부 쏘나타·아반떼 옵션을 사용한다. 기본가격·옵션 가격·선행 조건·구매 자금·차량 할부와 기존 대출 반영은 `owner-funded`와 같다. 미수집 유료 옵션은 선택하지 않는다. 새 가격 수집이나 모델 추가를 한 것은 아니다.

사회 초년생 옵션 포함 가격 4,000만원 한도, 가정 가족 지원 비율·상한, 연 6.5%/60개월, 가정 등록비 7%, 구매 당시 실수령 대비 월 차량 상환 20%/총 상환 45% 한도를 유지한다. 세금·금리는 실제 상품 계산이 아니다. 현재 월 적자 사례도 이미 차량을 보유한 설정이므로 배제하지 않는다. 세부 가정과 입력/정답 구분은 기존 `owner-funded/README.md`를 따른다.

학습 63,000명·검증 13,500명·평가 13,500명이다. 프로필 생성과 구매 선택에 같은 배치 시드를 기록하며, 구매 선택은 1,000행 단위로 배치 시드+행 시작 위치를 사용한다. `generation_config.json`과 기존 규칙 파일을 함께 보관해야 동일 결과를 재현할 수 있다. 각 생성 묶음을 다시 실행하여 결과가 같은지 검증한다.

## 검증 및 재현

`python -m tools.data.households.generate_extra_owners` 실행 후 bundled Node로 `tools/data/csv/exportExtraDomesticCsv.mjs`를 실행한다. 국내·수입차 기존 파일의 SHA256, 신규 ID 충돌, 재무 회계식·구매 자금 합계·옵션 의존성·CSV 값·컬럼 구조를 확인한다. `validation-report.json`과 `csv-validation.json`에 결과를 기록한다.

추가본은 기존과 같은 가상 패턴을 확대한 데이터다. 90,000건 증가가 실제 사람의 표본 증가나 실제 추천 성능 검증을 의미하지 않는다. 모델별 인원은 실제 시장 점유율이 아니며 보유 모델명·브랜드·차체·차급·식별자·생성 정보와 구매 내역의 정답 관련 필드를 특성 입력에 넣지 않는다.
