# 선호 기반 차량 결과 수정본

모든 행에 차량이 있는 최신 완성본은 `../preference-complete-v1/combined_training.csv`다. 이 폴더는 재무 입력을 보존해 선택 없음이 남아 있는 이전 단계이며 원래 조건 비교·검증용으로 보존한다.

선호가 추가된 206,156행의 **입력은 유지하고 차량 타깃을 다시 계산한 데이터**다. 원본 main 데이터와 preference-extended-v1의 CSV는 변경하지 않았다. 작업 브랜치는 ml/test다.

## 사용할 파일

- combined_training.csv: 결과를 수정한 전체 206,156행. 모든 원래 입력 8개, 추가 선호 4개, ID·분할·행 순서를 보존했다.
- examples.csv: 변경 전후 차량과 입력·비용을 함께 보는 소규모 예시.
- validation_report.json: 입력 보존·조건 검증·변경 건수·선택 모델 분포.
- before_after_comparison.json: 동일한 행으로 비교한 선호 일치 개선과 남은 절충 사유.
- generation_config.json: 가정·seed·점수식·학습 입력 목록·원본 해시.
- catalog.json / vehicle_identity_map.csv: 선택한 사양의 가격·정원·전장·연료·출처 및 차량 ID와 타깃 라벨의 관계.

이전 owners.csv/purchases.csv의 차량 결과는 과거 기록 보존용이며 이 새 타깃과 섞지 않는다. 새 결과에는 사양 ID·트림·가격·연료와 새로 계산한 초기 지급액·할부금·유지비·잔여액이 한 행에 포함된다. 과거 구매 내역을 새 차량의 구매 내역으로 재사용하지 않는다.

## 선택 규칙

1. 현재 입력과 선호를 먼저 고정한다. 선호·소득·자산·지출을 선택 차량에 맞춰 수정하지 않는다.
2. 알려진 기본 정원이 최소 인원 이상인 차량을 검토한다. 기본 정원이 없으면 알려진 좌석 옵션의 최솟값을 사용한다. 정원 미확인 차량은 제외한다. 정원 등록은 사용자 제공값을 포함하며 모두 제조사 검증값인 것은 아니다.
3. 기존 자료는 원래 월저축액을 보존하고, 비상자금은 현금성 자산 범위에서 생활지출 3개월분을 확보한다. 나머지 현금성 자산을 구매에 쓸 수 있는 자금으로 둔다. 기존 자료에 없던 월 여유자금 하한·가격 상한은 0(미지정)으로 둔다. 원래 8개 입력의 현금성 자산은 변경하지 않고 현재 상태에서의 가상 재선택으로 해석한다.
4. 신규 자료는 원래 생성한 저축·비상자금·구매자금·월 여유자금 하한·가격 상한을 보존한다. 이 변수들도 이번 출력에 기록해 숨은 판단 조건으로 남기지 않는다.
5. 구매가격에서 초기 지급액을 빼고 남은 원금을 60개월·연 6% 원리금균등 가정으로 계산한다. 월 유지비는 기존 에너지·보험·세금·정비 가정이다. 할부금과 유지비를 원 단위 올림한 뒤에도 월 여유자금 하한을 만족해야 한다. 추가 취득부대비·보조금·옵션·잔존가치는 미반영이다.
6. 적격 후보에 대해 `(가성비중요도×경제성 + 3×크기일치 + 3×연료일치 + 용도일치)/(가성비중요도+7)`을 계산한다. 경제성은 구매가격+60개월 유지비+할부이자를 가용 예산과 비교한다. 크기 점수는 기존 전장 범위와 거리 1m 선형 감점, 용도별 전장 목표는 기존 생성 규칙을 따른다. 크기·연료는 선호이며 필수 제외 조건이 아니다. 충전 환경은 사용하지 않는다.
7. 모델별 최고 점수 사양 하나만 남기고, 최고점과 100점 기준 2.5점 이내 모델 중 확률적으로 선택한다. 같은 조건에서 다양한 결과를 허용하되 낮은 점수 차량을 무작위로 뽑지 않는다. 가까운 후보가 없으면 한 모델만 선택될 수 있다.

수입차·일부 LPG 등 제원이 불충분한 후보는 전장 일치 점수를 받지 못해 데이터가 충실한 차량 쪽으로 선택이 치우칠 수 있다. 미확인 전장을 임의로 채우지 않았다. 전체 265개 사양을 보존하지만 선택 모델 수나 국산·수입 비율을 강제로 맞추지 않는다. 원래 PHEV/MILD_HYBRID는 카탈로그의 기존 비용 정책상 GASOLINE으로 정규화되어 있으며 원래 표기를 catalog.json에 보존한다. 전기·하이브리드 절감 효과를 만들어 넣지 않는다.

## 결과와 검증

- 기존 196,000행 중 라벨 변경 194,311행. 적격 차량 선택 124,768행, 선택 없음 71,232행.
- 신규 10,156행 중 라벨 변경 4,592행. 적격 차량 선택 6,508행, 선택 없음 3,648행.
- 전체 선택 없음은 74,880행이다. 예산·정원·가격 조건을 충족하지 못하면 차량을 강제로 넣지 않는다. NO-CHOICE는 명시적 결과이며 가격·차량 비용 0은 차량 미선택 표시다. 이때 월잔여액은 차량 비용을 추가하지 않은 기존 생활·상환·저축 차감 후 값이다.
- 선택 차량의 필수 조건 위반 0건. 벡터 연산으로 만든 결과를 별도의 스칼라 finance.assess 및 좌석 필터로 행별 재검증했다. 저장 후 모든 입력 셀·순서·행 수를 다시 대조했다.
- 기존 자료 중 동일 행을 대상으로 비교 가능한 82,398행에서 연료 선호 불일치는 65,781→24,209행으로 감소했다. 전장 비교 가능한 동일 32,426행에서 크기 선호 불일치는 21,719→11,506행으로 감소했다. 두 비교의 분모는 각각 고정했으며 신규 선택 없음으로 전환된 행은 포함하지 않는다.
- 신규 동일 입력 그룹 중 865개는 여러 모델이 선택됐다. 선호 불일치가 남은 경우에는 선택설명·적격 대안 존재 열로 후보 부재와 비용/다른 선호 절충을 구분했다. 불일치가 전부 사라진 데이터는 아니다.

선택 점수는 가정한 정책의 점수로 만족도나 실제 구매 확률이 아니다. 기존 8개 입력과 4개 선호만 쓰면 이번에 추가로 기록한 재무 계획의 차이를 설명할 수 없으므로 generation_config.json의 model_input_columns를 기준으로 연결해야 한다. 원래 차량·변경 여부·선택 사양·선택 후 비용·점수·설명은 학습 입력에 넣지 않는다. 기존 분할은 보존했으며 이전 보고서의 보류 선호 조합 겹침 한계도 그대로다. 별도 학습·모델 교체는 수행하지 않았다.
