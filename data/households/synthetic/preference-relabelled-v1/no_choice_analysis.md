# 선택 없음 74,880행 원인 분석

현재 combined_training.csv와 저장된 265개 사양 스냅샷을 사용해 모든 미추천 행을 재검사했다. 적격 차량이 있는데 놓친 행은 0건이다. 학습 데이터는 변경하지 않았다.

## 서로 중복되지 않는 대표 원인

| 원인 | 행 수 | 비율 |
| --- | ---: | ---: |
| 생활지출·기존 상환 후부터 월 가용자금 없음 | 28,429 | 38.0% |
| 저축까지 차감하면 월 가용자금 없음 | 1,208 | 1.6% |
| 최소 월 여유자금까지 확보하면 차량 예산 없음 | 664 | 0.9% |
| 남은 차량 예산으로 최소 유지비를 충당하기 어려움 | 31,560 | 42.1% |
| 유지비는 가능하나 구매자금·할부금까지 포함하면 부족 | 12,779 | 17.1% |
| 최소 정원과 가격 상한을 함께 충족하는 후보 없음 | 240 | 0.3% |

크기·연료·가성비 선호는 순위 점수이며 미추천을 발생시키는 필수 필터가 아니다. 위 원인은 정원·가격 교집합을 먼저 확인하고 생활지출→저축→여유자금→유지비→할부 순서로 대표 원인을 하나 배정한 것이다. 나중 단계의 문제도 동시에 존재할 수 있다.

## 부족 규모와 정책 가정

정원·가격 후보가 존재하는 행에서 필요한 추가 월 가용자금의 중앙값은 337,686원, 90백분위는 1,348,516원이다. 1,214행은 1만원 이하 차이이고, 25,850행은 50만원을 초과한다.

아래는 한 조건만 바꾸는 진단용 가정이며 권고안이 아니다. 행이 중복되므로 합산하면 안 된다.

| --- | ---: |
| 저축만0으로가정 | 18,309 |
| 최소여유자금만0으로가정 | 840 |

유지비 제외 시 적격이 되는 수는 유지비 계산의 영향 크기를 뜻한다. 에너지·보험·세금·정비비를 실제로 없앨 수 있다는 뜻이 아니다. 비상자금·저축·장기 할부 가정도 같은 방식으로 해석해야 한다.

## 기존 데이터의 자금 시점

기존 미추천 71,232행 모두 현금성 자산이 원래 구매 내역의 구매직후 현금과 일치한다. 원래 구매직전 현금을 사용하되 나머지 정책을 동일하게 놓으면 8,881행에 적격 후보가 생긴다.

현재 재무 상태에서 새 차를 추천한다는 해석이면 구매 후 잔액 사용이 가능하다. 반면 원래 차량을 구매한 당시의 선택을 학습하려면 자금 시점이 맞지 않는다. 이를 검토 없이 구매 전 현금으로 덮어쓰면 기존 입력 보존 요구를 위반하므로 이번 분석에서는 변경하지 않았다.

## 데이터 활용 판단

현재 입력·가정을 유지한다면 다수의 NO-CHOICE는 정상적인 미추천이다. 차량 결과를 억지로 채우면 다시 재무 괴리가 생긴다. 향후 데이터 목적을 현재 상태의 신규 구매 추천으로 둘지 원래 구매 당시 선택 설명으로 둘지 정하고, 저축·유지비·구매자금·할부 가정을 그 목적에 일관되게 맞춰야 한다.

전체 행별 원인: no_choice_details.csv. 작은 예시: no_choice_examples.csv. 상세 집계: no_choice_analysis.json.

재현: `python -m tools.data.households.analyze_no_choice`
