# 현재 정책 기반 신규 100,000행과 후보 비교 데이터

기존 306,429행과 별도로 독립 생성했다. 기존 원본·모델과 main은 변경하지 않았다.
실제 인구 비율·시장 점유율·구매 확률을 추정한 데이터가 아니다.

## 생성 기준

- 시드 20261026. 서로 다른 재무 그룹 25,000개를 먼저 생성하고, 각 그룹에 독립적인 선호 4개를 붙였다. 입력 중복은 버리고 다시 추출했다.
- 월소득은 중앙값 550만원·로그 표준편차 0.65의 가정 분포를 월 150만~6,000만원으로 제한하고 1,000원 단위로 반올림했다.
- 일반 그룹의 생활지출은 소득 35~85%, 기존 월 상환은 60% 확률로 소득의 0~18%다. 재무 그룹 10%는 소득의 100~135% 생활지출, 별도 10%는 대출 상환까지 차감한 월 여유금이 정확히 0원이다.
- 예금은 차량 선택과 무관하게 100만원~10억원 로그 균등 분포에서 정수 원 단위로 생성했다. 저축·비상자금·추가 월 버퍼·차량 할부·금리는 0, 연간 주행거리는 공통 15,000km다.
- 선호 연료는 5종 또는 상관없음, 선호 크기는 any/small/medium/large, 희망 인원은 0/2/4/5/6/7/9명, 네 중요도는 각각 1/3/5에서 독립 추출했다. 용도는 평가하지 않는다.
- 차량값 전액을 지불할 수 있어야 한다. 월 유지비가 월 여유금을 넘으면 **차량값을 뺀 예금**으로 생활 적자와 유지비 부족액을 최소 12개월 충당해야 한다. Decimal 독립 계산으로 판정을 교차 확인했다.
- 가성비는 구매비·유지비 절약을 중요도에 따라 반영한다. 가성비가 낮다고 비싼 차량을 보상하지 않는다. 예산 상단 가점과 용도 점수도 없다.
- 연료·크기·정원은 현재 서비스와 같은 상대 평가다. 부족한 정원을 적격 탑승 사양으로 바꾸거나 선택 후 입력을 수정하지 않는다.
- 각 사례의 재무 적격 모델 중 최대 16개 서로 다른 모델을 균등 추출하고, 모델별 적격 사양 하나를 추출한다. 트림 수가 많은 모델에 추출 가점을 주지 않는다. 모든 후보에서의 전역 최적 선택을 보장하는 CSV가 아니다.
- 선택 차량은 이 후보들의 효용에 온도 0.06 softmax를 적용해 추출한다. 이 확률은 생성기 추출 확률이며 실제 구매 확률이 아니다.
- 비교 학습 정답은 ML 항목을 제외한 현재 비용·연료·크기·정원의 가중 평가다. 효용 차이가 0.01 이상인 같은 사용자 내 차량 쌍을 최대 8개 추출한다. 선택되지 않은 차량을 모두 오답으로 취급하지 않는다.

## 분리 및 실제 학습량

재무 그룹 단위로 학습/검증/평가를 70/15/15%로 분리했다. 차량 17개 브랜드·모델은 학습과 검증의 **후보 비교 배열**에서 제외하고 평가에 사용했다. 이 모델만 적격인 학습 사례의 CSV에는 차량이 기록될 수 있지만, 그 차량의 특징·비교 정답은 학습 배열에 들어가지 않는다.

| 구분 | 전체 사례 | 후보가 있는 사례 | 후보 조합 | 비교 쌍 |
|---|---:|---:|---:|---:|
| 학습 | 70,000 | 41,060 | 584,184 | 301,102 |
| 검증 | 15,000 | 8,912 | 126,700 | 65,289 |
| 평가 | 15,000 | 9,004 | 128,140 | 66,870 |
| 합계 | 100,000 | 58,976 | 839,024 | 433,261 |

전체 CSV는 선택 차량 60,280행, 재무 부적격 `NO-CHOICE` 39,720행이다. CSV의 선택 차량 사례 수와 비교 배열의 사례 수는 평가 전용 차량 제외로 다르다. 후보가 없거나 비교할 차이가 없는 사례에는 순위 학습 손실을 만들지 않는다. 추천 없음은 재무 필터가 판단한다.

## 파일

- `profiles.csv`: 한글 컬럼의 신규 100,000행. 정수 금액·주행거리·중요도. 예상 유지 기간은 소수 개월이다.
- `profiles.jsonl`: 정밀한 재현을 위한 같은 입력의 Profile 스키마.
- `candidate_pairs.npz`: 특징, 효용 정답, 비교 쌍, 사용자 ID, 차량 인덱스, 분리 구분. 학습은 이 배열의 학습 분할만 사용했다.
- `catalog.json`: 생성에 사용한 281개 차량 사양 스냅샷.
- `generation_report.json`: 난수·생성 설정·수량·해시.
- `validation_report.json`: 저장본 재검사. 재무 위반·재무 그룹 누수·평가 전용 모델 학습 유입·다른 사용자 간 비교 0건.

학습은 검증 비교 쌍 정확도로 12개 epoch 중 체크포인트를 선택했다. 정규화는 학습 후보만 사용하고, 평가 데이터는 체크포인트 선택에 쓰지 않았다.

모델: `ml/outputs/models/candidate-preferences/20261026-100k-v1`.
기존 모델은 보존하며 새 모델은 선호 크기·인원·중요도·예금 충당 특징을 포함하는 별도 `candidate-preferences-v3` 스키마다.

## 재현

저장소의 `ml` 디렉터리에서, 이미 존재하지 않는 새 출력 경로를 지정한다.

```powershell
.\.venv\Scripts\python.exe -m vehicle_matching.train_preference_population --data-dir ../data/households/synthetic/new-output --output outputs/models/candidate-preferences/new-run --source-model outputs/models/candidate-retrained/20261022-165001-specifications-v1 --seed 20261026 --epochs 12
.\.venv\Scripts\python.exe -m vehicle_matching.audit_preference_population ../data/households/synthetic/new-output
.\.venv\Scripts\python.exe -m vehicle_matching.evaluate_preference_population ../data/households/synthetic/new-output outputs/models/candidate-preferences/new-run outputs/models/candidate-retrained/20261022-165001-specifications-v1
```

비용 가정은 `metadata.json`의 보험·정비·세금·에너지 단가 스냅샷이며 실시간 시세·견적이 아니다. 새 자료를 수집하거나 실제 구매 결과로 정답을 바꾸지 않았다.
