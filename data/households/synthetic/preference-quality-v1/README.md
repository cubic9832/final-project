# 품질 기준을 통과한 추천 학습 데이터 v1

현재 사용할 학습본은 **combined_training.csv**다. 전체 206,156행에 실제 카탈로그의 추천 차량 사양이 연결된다. 이전 원본과 확장본·완성본은 변경하지 않고 보존했다. 모든 작업은 ml/test에서 수행했고 main은 읽기만 했다.

## 데이터 구성

| 출처 | 행 수 | 처리 |
| --- | ---: | --- |
| 기존 입력 유지 | 66,835 | 원래 재무 8개 입력과 네 선호 유지 |
| 기존 소액 보정 | 23,790 | 월소득만 원래 소득 10%·30만 원 중 작은 상한 이내 보정 |
| 신규 독립 생성 | 115,531 | 재무·선호를 먼저 생성하고 품질 기준을 통과한 입력에서 차량 선택 |
| 합계 | 206,156 | 전 행 차량 있음 |

기존 196,000행 중 90,625행을 채택했다. 나머지 105,375행과 이전 독립 생성분 10,156행의 자리는 새 합성 사례로 대체했다. 기존 행을 삭제하거나 덮어쓴 것이 아니라 별도 학습본에서 선별한 것이다. 105,375행 중 33,292행은 재무 불량 때문이 아니라 보류 선호 조합의 학습·검증 유입을 차단하기 위해 제외했다. 원본별 처리와 이유는 legacy_screening.csv에 있다.

## 품질 규칙

1. 최소 탑승 인원·등록 가격 상한·월 부담·비상자금 보존을 충족해야 한다. 충전 환경은 제외 조건이 아니다.
2. 원래 최소 월 여유자금에 더해 `max(10만 원, 월소득 5%, 월 차량비 10%)`를 남긴다. 소수 계산 경계의 오차를 막기 위한 2원 여유도 내부 판정에 둔다.
3. 적격 모델명 3개 이상, 선호 우선 단계의 근접 점수 비교 모델 2개 이상이어야 한다. 모델당 최고 사양 하나만 비교하므로 트림 수로 선택 확률을 늘리지 않는다.
4. 적격 후보 중 크기와 연료가 모두 맞는 후보가 있으면 그 단계에서 선택한다. 두 조건 동시 충족 후보가 없을 때만 한 선호를 절충한다. 두 조건이 모두 어긋나는 결과는 학습본에 넣지 않는다. 크기 절충도 지정 전장 범위에서 500mm 이내로 제한한다. 연료 ‘상관없음’은 일치로 처리한다.
5. 우선 단계 안에서 경제성·용도 등을 비교한다. 최고 점수와 100점 기준 12점 이내 모델 중 온도 0.06의 softmax로 추첨한다. 같은 조건에서도 선택이 달라지되, 사양이나 재무 조건을 어기는 모델은 넣지 않는다.
6. 기존 월소득은 필요한 경우에만 1,000원 단위로 소액 보정하고 상한을 넘기지 않는다. 다른 기존 ML 입력과 네 선호는 보존한다. 큰 보정이 필요하거나 비교 후보가 부족한 사례는 보존본에 남기고 새 입력을 생성한다.
7. 신규 입력에는 사후 소득 보정을 하지 않는다. 소득·자산·지출·기존 상환·주행거리와 용도·선호를 먼저 생성한다. 후보가 부족하면 그 입력을 기각하고 새 입력을 생성한다. 선택 차량을 보고 선호나 재무를 역으로 정하지 않는다. 같은 재무 그룹에는 같은 금융 값과 데이터 분할을 적용한다.

신규 소득은 중앙값 550만 원·로그 표준편차 0.5의 가정 분포를 250만~1,500만 원 범위로 제한한다. 주거비는 소득 10~22%, 기타 생활소비 15~30%, 기존 월 상환 0~12%, 저축 5~20%, 현금성 자산은 월소득 2~36개월분을 가정한다. 부채 잔액은 월 상환액×12~120개월 가정이다. 이 분포와 재무 적격에 따른 채택은 실제 인구·시장 분포 추정이 아니다. 동일 입력을 최대 4회 반복하며 총행 수를 맞추기 위해 마지막 묶음은 일부 반복만 포함할 수 있다.

할부는 비교용 60개월·연 6% 가정이며 기존 보험·세금·정비·에너지 추정을 사용한다. 선택 옵션·취득부대비·보조금·잔존가치는 미반영이다. 이 계산은 금융 승인이나 실제 구매 가능성 보증이 아니다.

## 제원 보완과 미확인 처리

수입 6개 모델·18개 사양에 제조사 차체 전장 참조값을 연결했다. 가격·파워트레인·원래 연료는 변경하지 않았다. 근거와 적용 범위는 length_evidence.json에 있다. 국내 전용 트림 자료가 없는 경우 해외 동일 세대 차체의 제조사 참조값임을 명시했다. 모델명만 같고 차체 세대가 다른 차에는 전용하지 않는다.

전장 미확인은 점수 0의 부적합 차량으로 처리하지 않고 중립 0.5와 제원 확인 대기로 구분한다. 다만 크기 선호가 들어가는 확정 학습 타깃에는 확인 가능한 제원이 있는 후보를 사용한다. 이는 해당 차량이 실제로 부적합하다는 판정이 아니라 학습 근거 부족의 구분이다. 여전히 미확인인 다른 후보를 임의 숫자로 채우지 않았다.

PHEV는 선호 비교에서 하이브리드로 구분하고 원래 연료를 별도 열에 보존한다. 비용 계산은 기존 가솔린 추정 정책을 유지해 전기 주행 절감액을 만들어 넣지 않았다. 마일드 하이브리드는 기존 가솔린 분류를 유지한다. 정원은 기존 등록값을 사용하며 모두 제조사 검증값인 것은 아니다.

숫자 비교는 같은 행들의 인과 효과가 아니다. 입력 선별·신규 대체·제원 보완·정책 변경을 함께 적용한 두 묶음의 비교다. 연료 선호 불일치는 61,183/168,693행(36.3%), 크기 선호 불일치는 19,045/206,156행(9.2%)으로 남으며, 이는 동시 충족 적격 후보가 없어서 한 선호만 절충한 사례다. 불일치가 모두 없다고 주장하지 않는다. 선택 모델명은 46개이며 실제 시장 비중을 맞추기 위한 쿼터는 적용하지 않았다.

추가 여유자금 최솟값은 100,087원, 중앙값은 1,208,790원이다. 모든 행에 후보 모델 3개 이상과 비교 후보 2개 이상이 있다. 신규 동일 입력 그룹 중 여러 모델이 선택된 그룹은 27,588개다. 후보별 원금·유지비를 생성기와 별도의 Decimal 계산으로 전수 재검증했다. 결측·선택 없음·필수 조건 위반·큰 보정·그룹 분할 누수는 0건이다. 전체 수치는 validation_report.json을 따른다.

## 평가와 사용 파일

- combined_training.csv: 학습용 전체 데이터, 한글 컬럼과 정수 수치.
- examples.csv: 작은 예시. imported_examples.csv는 수입차 선택 사례.
- legacy_screening.csv: 기존 196,000행 각각의 채택·보존 이유.
- generation_report.json / generation_config.json: 생성·기각·보정 정책과 seed.
- validation_report.json: 독립 전수 검증.
- catalog.json / vehicle_identity_map.csv / length_evidence.json: 차량·식별자·근거.

재무 그룹별로 분할하고 반복 사례를 같은 구간에 둔다. 비용 중요도·크기·용도의 고정 보류 조합은 기존 사례도 포함해 학습·검증에서 제거한다. 평가 행의 평가유형에서 새재무상황평가와 새선호조합평가를 구분한다. 단순히 새 데이터에 평가 이름을 붙인 것이 아니라 전체 학습본에서 보류 조합 유입을 검사한다.

학습 입력은 기존 8개 항목과 네 선호, 선택에 사용한 저축·비상자금·구매투입자금·최소 여유자금·가격 상한이다. 선택 차량 정보·선택 후 비용·점수·원래 차량·보정 전 소득·보정액·사례 출처·프로필 ID·평가유형은 학습 입력에서 제외한다. 실제 구매 만족도 정답이 아닌 명시적 정책에 따른 합성 선택이다. 모델을 재학습하거나 서버를 교체하지 않았다.

재현: `python -m tools.data.households.build_quality_training`

독립 전수 검증: `python -m tools.data.households.audit_quality_training`

핵심 테스트: `python -m unittest tools.data.households.tests.test_quality_training`
