# 재무 절대 조건 · 선호 상대 평가 데이터

기존 v3의 306,429행을 재무·원래 네 가지 선호·분리 구분 그대로 보존하고, 변경된 선택 정책으로 차량 정답을 다시 생성했다. v3와 main은 수정하지 않는다. 이번 파일이 새 정책에 맞는 학습본이다.

## 최종 추천 규칙

- 구매 투입 가능 자금, 비상자금, 월 저축, 기존 월 상환, 차량 할부·유지비와 최소 월 여유자금, 명시한 구매가격 상한을 금액의 절대 조건으로 적용한다.
- 비상자금을 제외한 구매 투입 자금을 먼저 사용하고 부족분은 60개월·연 6% 할부로 가정한다. 실제 대출 승인 판단이 아닌 비교 가정이며, 사용자가 설정한 최소 여유자금 외의 암묵적 10만원/소득 5% 추가 버퍼는 제거했다.
- 연료·크기·탑승 인원·용도는 제외 조건이 아닌 가중 점수다. 제원 미확인은 0.5 중립값이다. 충전 환경은 제외 조건이 아니다.
- 연료·크기 동시 충족 우선 단계, 크기 500mm 제한, 최고점과 0.12 이내 후보 제한, 최소 확률 제한을 제거했다.
- 재무 적격 모델이 3개 이상이면 서로 다른 모델 3개, 1~2개면 그 수만 제시한다. 하나도 없으면 추천 가능한 차량 없음이다. 비적격 차량으로 수를 채우지 않는다.

## 가중치와 정답

기존 가성비 중요도 외에 공간·연료·탑승 인원·용도 중요도 네 열을 추가했다. 각 값은 차량을 선택하기 전에 독립적으로 1~5에서 생성하며, 반복된 동일 입력은 같은 가중치를 공유한다. 기존 원래 입력은 수정하지 않는다.

가성비는 5년 구매·유지·이자 비용의 예산 대비 비율, 크기는 선호 전장 범위와 거리, 연료는 선호 일치, 인원은 확인 정원/희망 인원의 비율(최대 1), 용도는 전장 기반 가정 점수다. 인원 점수는 초과 승차를 허용한다는 의미가 아니며 추천 카드에 실제 정원 부족을 표시한다. 용도 점수는 실내 공간·안전·실제 만족도의 검증값이 아니다. 서비스는 같은 점수 구성에 ML 참고 점수 가중치 1을 더한다. 데이터 생성 시 ML 참고값은 중립 0.5다.

동일 조건에서 복수 선택이 가능하도록 학습 정답은 재무 적격 모델 전체에서 가중 효용 softmax(temperature 0.06)로 선택했다. 후보를 점수 차이나 확률로 잘라내지 않는다. 따라서 학습 정답이 결정적 상위 3개 밖일 수도 있으며, 단일 선택 정답 일치율과 최종 가중 순위의 품질은 구분해야 한다.

| validation_report.json | 전체 독립 비용·상위 3개·입력 보존·누수 검사 |

이번 입력은 원래 재무 적격 사례만 모은 데이터이므로 전부 3개 후보가 나온다. 추천 없음과 1~2개 후보 반환은 서비스/정책 경계 테스트로 별도 확인했다. 학습 205,673행, 검증 33,611행, 평가 67,145행으로 분리했다. 학습에 없는 검증·평가 라벨은 없다.

전체 306,429행과 추천 919,287행에서 금액 위반·잘못된 상위 3개·누락·분할 누수 0건이다. 기존 재무·선호·분리 구분을 보존했고, 1,000행에서 벡터 생성 점수를 실제 서비스의 스칼라 가중 점수와 교차 확인했다.

재학습 모델은 `ml/outputs/models/preference-financial-v4/20261022T120014`에 있다. 같은 설정의 MLP 단일 seed 기준 모델이며 API의 기존 pair ranker 가중치와는 별도 실험이다. API는 변경된 재무 필터와 선호 상대 점수 코드를 사용하지만 이 분류 모델을 서비스에 배포하지는 않았다.

```powershell
$env:PYTHONPATH='.;ml'
python -m tools.data.households.rebuild_financial_choices
python -m tools.data.households.audit_financial_choices
ml/.venv/Scripts/python.exe -m experiments.train_quality_choices --data-dir data/households/synthetic/preference-financial-v4
```
