# 일반 취향 기반 데이터 v3

사용자 10,000명·비교 선택 100,000쌍입니다. 모든 96개 모델·308개 사양을 활용하며 모델별 학습 최소 20회/검증 5회/평가 5회와 사양별 전체 최소 1회를 충족합니다.

브랜드·차량 모델 선호는 입력과 선택 효용에서 제외했습니다. 사용자의 비용·차체·연료·전장 크기·주행거리·충전 여건에 따라 비교 선택을 새로 생성했습니다. 모든 사용자 preferred_brands=[], model_affinities={}, 해당 효용 가중치 0을 전체 감사에서 확인합니다.

이전 데이터의 정답을 재사용하거나 화면만 숨긴 버전이 아닙니다. 기존 68개 배열의 브랜드/모델 슬롯은 중립 상수로 예약되어 있습니다.

- `configuration.json`: identity_preferences=false와 최소 등장 횟수.
- `coverage_report.json`: 전체 모델·사양의 실제 비교 횟수.
- `validation_report.json`: 전체 데이터 재검증 결과.
- `preview.json`: 실제 생성된 첫 20명의 입력과 비교 선택.
- `shard-*`: 프로필·선택·이유·감사 기록 및 학습 배열.

재학습 모델과 실제 서버 적용 기록: `ml/outputs/models/scenario-choices/20261029-v3-broad-taste-10k`.
