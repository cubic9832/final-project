# 이미 차량을 보유한 사람의 가상 특성 데이터

이번 버전은 구매 가능 여부를 평가하는 이전 `ownership` 데이터와 다른 독립 데이터다. 만 20~59세 차량 보유자 10,000명을 새로 생성하고 전원에게 모델 1개를 부여한다. 구매 보류·차량 미배정 행은 없다. 기존 차량 목록만 재사용하고 개인 재무 값은 보유자 집단 분포에 따라 다시 생성했다.

프로필은 P000001~P010000이다. 이전 파일의 같은 P번호와 동일 인물이 아니므로 연결하지 않는다. 차량 코드도 이번 버전은 OWN001 형식이다. 원본·이전 결과 파일은 유지한다.

## 파일

- `차량보유자_특성_학습데이터.csv`: 한 행이 차량을 이미 보유한 가상 개인 1명이다. 한국어 컬럼과 원 단위 금액을 사용한다.
- `차량별_보유자특성_요약.csv`: 14개 모델별 보유자 수·평균 연령·연소득 중앙값과 10/90백분위·현금·소비·상환액·최빈 연령대/목적이다. 실제 소비자 통계가 아닌 생성 결과다.
- `vehicle-label-catalog.json`: 모델 코드와 대표 사양·공식 가격/연비 출처를 보관한다. 연료별·Hybrid 이름의 사양을 모델 단위로 합친다. 이번 정답은 연료나 트림이 아닌 모델이다.
- `generation-audit.json`: 생성에 쓰인 가상 집단을 기록한다. 학습 입력에 넣지 않는다.
- `validation-report.json`: 행 수·분할·재현성·입력 해시 검증 결과다.

## 구성과 가정

먼저 모델을 지정한 뒤 차급별 보유자 특성 분포에서 사람의 조건을 생성한다. 실제 시장 점유율을 알 수 없어 모델마다 714~715명 수준으로 거의 균등 배분했다. 이는 학습용 모델별 사례 확보 목적이며 실제 인기 순위로 해석할 수 없다. 후보 목록에는 기존 가격·연비 연결 자료가 있는 14개 모델만 포함되며 전기차 등 시장 전체를 대표하지 않는다.

경형·소형은 비교적 낮은 연령·소득과 출퇴근 목적, 중형 이상은 더 높은 소득·가족 구성 비율을 가정한다. 소득은 로그정규분포이며 표준편차 계수는 0.4다. 25% 확률로 다른 차급의 집단 설정을 다시 뽑고, 연령·소득·현금·가족 구성에도 난수를 사용하여 차량 간 특성이 겹치게 한다. 동일 소득·연령의 사람이 서로 다른 차를 보유할 수 있다. 성별은 50:50 확률로 생성하고 차량 선호 차이를 강제하지 않는다.

가족 구성·차량 이용 목적도 분포에 포함되지만, 모든 가족이 큰 차를 보유하거나 고소득자가 반드시 비싼 차를 보유하도록 제한하지 않는다. 현금이 적거나 월 적자여도 이미 구매한 차량이 있다는 설정을 유지한다. 부모 지원·과거 구매 당시 소득은 이번 데이터에 관측된 것으로 추가하지 않는다. 해당 정보가 없다는 것이 지원이 없었다는 의미는 아니다.

현재 개인의 평균 월 재무 상태를 표현한다. 월별 실제 관측치를 평균낸 데이터가 아니라 가상 평균값을 직접 생성했다. 과거 구매 시점·과거 가격·연식별 소유 이력은 재현하지 않는다. 개인 연간세전소득에는 비취업자의 비근로 소득 가정도 포함되므로 모든 값을 급여 연봉으로 부르면 안 된다.

상위 `owner_population_config.json`에 시드, 규모, 집단별 연령·소득·현금 배수·가족 비율·목적 비율과 주요 가정을 기록한다. 세전소득의 82%를 연 실수령액으로 보고 12로 나누는 간소화 가정을 사용한다. 실제 세금 계산식이 아니다. 현금 외 금융자산·보증금·부동산을 분리하고 차량 가치는 자산·순자산에서 제외한다. 대출잔액은 주택 관련 담보대출과 개인 신용대출의 가상 합계다. 차량 할부·가족 지원금·차량 취득자금은 따로 모델링하지 않았다.

## 컬럼과 학습 사용법

- 기본 특성: 나이, 연령대, 성별, 직업 유형, 경력, 가구원·부양인원, 이용 목적, 연간 주행거리. 경력 3년 이하를 사회 초년생으로 정의한다. 경력과 직업은 현재 상태를 뜻하며 비취업자도 과거 경력이 있을 수 있다.
- 소득: 개인 연간 세전소득, 개인 평균 월 실수령소득, 가구 평균 월 실수령소득을 구분한다. 개인 자산과 가구 소득을 혼동하지 않는다.
- 자산: 개인 현금성·기타금융·주거보증금·부동산, 차량 제외 총자산과 순자산. 순자산은 총자산−대출잔액이다.
- 소비: 월 주거비+기타 생활 소비=소비 합계다. 대출 상환과 저축은 소비 합계에 중복 합산하지 않는다. 월 잔여액=개인 월 실수령−소비−대출 상환−저축으로 적자를 허용한다.
- 정답: 보유차량 라벨코드 또는 모델명 중 하나를 사용한다. 브랜드·모델·차체·차급은 정답 관련 열이므로 모델 예측 입력에서 모두 제외한다.
- 관리용: 프로필 식별자, 합성 여부, 라벨 근거, 생성규칙 버전, 시드, 데이터 구분도 입력에서 제외한다. 연령대와 나이, 총자산과 구성 항목 등 중복 파생 항목은 학습 시 필요한 표현만 선택할 수 있다.

학습 7,000명·검증 1,500명·평가 1,500명으로 분리한다. 요약 CSV는 전체 합성 모집단의 설명용이며 학습 전처리·차량별 프로토타입은 반드시 학습 구간에서만 계산해야 평가 정보 유출을 피할 수 있다. 균등한 모델 분포에서 나온 분류 확률을 실제 시장 구매 확률로 표현하지 않는다.

이 데이터로 사용자의 조건과 비슷한 보유자 집단을 찾는 구현 실험을 할 수 있다. 그러나 여기서 학습한 관계는 생성 가정이며 실제 구매자 조사 결과가 아니다. 소득/자산 요건이나 구매 자격의 판정 기준으로 사용하지 않는다.

## 재현

저장소 루트에서 `python -m tools.data.households.generate_owner_population` 실행 후 bundled Node로 `tools/data/csv/exportOwnerPopulationCsv.mjs`를 실행한다. 테스트는 `python -m unittest discover -s tools/data/households/tests -t .`다.
