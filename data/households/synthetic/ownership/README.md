# 20~50대 조건별 가상 보유 차량 라벨

기존 일반 프로필 중 만 20~59세만 사용한다. 경계 사례와 60세 이상은 제외한다. 원본 재무 정보와 프로필별 학습/검증/평가 구분을 보존하며, 원본 파일은 변경하지 않는다.

## 학습용 CSV

프로필 식별자는 현재 학습용 CSV의 행 순서대로 P000001~P007245를 사용한다. `label-audit.json`도 같은 새 식별자를 사용한다. 기존 재무 데이터와 연결할 때는 `profile-id-map.json`의 원본 식별자를 사용한다. 원본 데이터 자체의 식별자는 변경하지 않았다. 입력·라벨·행 순서·학습 구간은 식별자 변경 전과 동일하다.

`20~50대_조건별_가상보유차량_학습데이터.csv`는 프로필당 1행이다. 성별·이용 목적·차체 선호·연간 주행거리는 새로 만든 합성 입력이다. 성별과 연령에 따른 선호 차이를 임의로 강제하지 않는다. 나머지 재무 금액은 기존 프로필에서 가져오며 원 단위다. 개인과 가구 공동 예산은 예산_범위로 구분한다. 인출 가능 현금은 총자산이 아니며 묶인 주거보증금을 차량 구매 재원에 합산하지 않는다.

구매결과_라벨은 가상구매/구매보류다. 가상구매인 경우 차량 라벨코드·모델·차체·차급·연료를 부여하고 보류이면 해당 칸은 비운다. 모델 예측 학습은 가상구매 행을 대상으로 하거나 구매 여부와 모델 예측을 나눠 수행한다. 구매보류는 현재 차량이 없다는 관측 사실을 의미하지 않는다. 여기서 가상보유는 이번 합성 시나리오의 구매 결과를 뜻하며 과거 구매 시점과 현재 자산 변화까지 재구성한 소유 이력이 아니다.

입력은 나이·성별·예산 범위·가족 구성·소득·현금·보증금·비상금·소비·저축·기존 대출·교통비·이용 목적·선호·주행거리다. 예측 대상은 구매결과와 차량 라벨이다. 프로필 식별자, 생성 정보, 데이터 구분은 관리용으로 입력에서 제외하고, 모델·차체·차급·연료 등 정답의 다른 표현을 모델 예측 입력으로 넣지 않는다. 진단용 결과 파일의 구매 후 잔여액·선택 확률도 입력으로 사용하지 않는다.

## 선택 규칙

1. 가격과 연비가 1건으로 연결된 기존 국내 차량 사양만 사용한다. 모델·연료별로 연결 가능한 가장 저렴한 대표 트림을 하나 택해 트림 수가 많은 모델이 유리해지는 편향을 줄인다. 전체 시장의 모든 모델을 포함하지 않으며 전기차는 현재 연결된 가격·전비가 없어 제외한다.
2. 등록비를 가격의 7%로 가정하고 목표 비상금을 남긴 현금에서 등록비와 선수금을 지불한다. 부족한 차량 가격은 연 7%, 60개월 원리금균등으로 계산한다. 등록비·세금·금리는 실제 견적이 아닌 시뮬레이션 가정이다.
3. 생활 소비·기존 대출 상환·목표 저축을 뺀 월 잔여액의 85% 이내에서 추가 할부·유지비를 감당할 수 있어야 한다. 기존 교통비 중 50%는 대체되는 것으로 가정한다. 기존 대출 상환액은 소비에 중복 포함하지 않는다.
4. 후보 안에서 현금·소득에 따른 목표 가격과의 거리, 가족 구성·가족 이동 목적, 차체 선호, 출퇴근 목적, 장거리 운행 시 하이브리드 가중치를 반영한다. 점수의 softmax 확률로 1개를 선택한다. 저소득·고자산과 고소득·고부채가 같은 결과로 처리되지 않도록 가용 현금과 월 현금흐름을 함께 평가한다.
5. 모든 후보가 탈락하면 구매보류다. 현금이 높아도 월 적자이면 보류될 수 있다. 기존 만기일시 대출의 만기 원금 조달까지 해결한 계산은 아니다.

정확한 비용·가중치·차체/차급 수동 분류는 상위 폴더의 `ownership_config.json`에 기록한다. 차체/차급과 소비자 선호는 가정이며 등록 통계에서 얻은 사실이 아니다. 하이브리드는 km/L 연비와 가솔린 단가로 연료비를 계산한다. 후보 수·정규화된 선택 확률·선택된 차량의 예산 계산은 `label-audit.json`, 출처를 포함한 차량 사양은 `vehicle-label-catalog.json`에 보관한다.

## 재현과 검증

저장소 루트에서 `python -m tools.data.households.label_ownership`를 실행하고 bundled Node의 `tools/data/csv/exportOwnershipCsv.mjs`로 CSV 두 개를 내보낸다. 같은 입력과 설정·시드로 같은 라벨이 나온다. 프로필 중복·연령 필터·예산 제약·원본 분할 보존을 확인하며 `validation-report.json`에 현금 구간별 결과를 기록한다. 기존 더미 데이터의 높은 적자 비중도 이어받으므로 보류율을 실제 소비자의 구매율로 해석하지 않는다.

이 데이터는 사용자가 요청한 가상 선택 관계를 구현한 학습 흐름 검증용 자료다. 실제 보유 경향이나 추천 정확도를 입증하지 않는다. 실제 자료 확보 후 선호 관계와 선택 확률을 교체하고 실제 평가 자료를 별도로 사용해야 한다.
