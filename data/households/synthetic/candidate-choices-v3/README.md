# 재무·이용 조건·선호 기반 가상 차량 선택 v3

기존 v2 데이터는 보존하고 새 규칙의 결과를 이 폴더에 저장했다. 실제 구매 기록이 아닌 합성 데이터이며 기존 추천 서비스나 모델 가중치는 변경하지 않았다.

## 파일

- choices.csv: 한글 전체 데이터. 숫자 열은 정수다. 금액은 원, 거리는 km, 연금리는 퍼센트다.
- examples.csv: 처음 5개 선택 가능 재무 그룹의 주요 열을 추린 읽기용 예시. 학습용이 아니다.
- catalog.json: ml/test 작업본의 76개 모델명·265개 사양과 출처 스냅샷. 모델명에는 파생 표기가 포함된다.
- generation_config.json: seed, 계산 가정, 한영 필드 대응, 카탈로그 해시.
- validation_report.json: 전체 생성 결과의 적격·충돌·다양성·분할 검사.

재현: python -m tools.data.households.generate_candidate_choices
검증: python -m unittest tools.data.households.tests.test_candidate_choices
기본 재무 그룹 1,000개, 선호 최대 3종, 동일 입력당 4회 추첨. seed=20261021.

## 이번 생성 규칙

재무 정보와 구매투입가능자금을 먼저 만들고, 용도·인원·크기·연료·중요도·선택적 가격 상한을 만든다. 이 입력 전체를 확정한 다음 후보를 평가하고 차량을 추첨한다. 선택한 차량을 보고 소득이나 선호를 수정하지 않는다. 재무·선호·선택 RNG를 분리한다.

필수 조건은 최소 정원, 명시한 구매가격 상한, 월 부담 한도다. 월 부담에는 할부금과 보험·세금·정비·에너지 유지비를 포함한다. 생활비·기존 대출 상환·목표 저축·최소 월 여유자금은 먼저 확보한다. 후보가 없으면 선택 차량 칸은 비우고 사유를 표시한다. 정원 옵션 확인이 필요한 사양은 확정 선택에서 제외한다. 기존 정원 정책의 일반 미확인 차량 2~4인 가정은 유지하므로 모든 좌석이 제조사 확인값인 것은 아니다.

가성비·크기·연료·용도는 선호 점수다. 작은 크기나 특정 연료와 일치하지 않는 차량도 선택할 수 있다. 충전 환경은 입력 열과 제외 조건 모두에서 뺐다. 가족 이동은 최소 4·5·6명, 나머지 용도는 1·2·4명이며 5명은 중간/큰 크기, 6명은 큰 크기로 선호를 생성해 흔한 입력 충돌을 줄인다. 이는 합성 분포의 가정이다.

차종(세단/SUV 등)은 현재 통합 카탈로그에 신뢰할 수 있는 공통 필드가 없어 생성하지 않았다. 차량 이름으로 추측한 차종을 정답에 넣지 않는다. 별도의 필수 차종·주차 크기 제한도 이번 묶음에는 없다.

## 구매·유지비 가정

구매투입가능자금은 유동자산에서 비상자금을 뺀 금액의 30~100%로, 차량을 보기 전에 생성한다. 선택 차량 초기 지급액은 그 자금과 차량 가격 중 작은 값이다. 나머지는 60개월·연 6% 원리금균등 할부로 계산한다. 현금으로 전액 충당하면 할부금은 0이다. 이는 비교용 시나리오이며 대출 승인이나 실제 적용 금리를 뜻하지 않는다.

추가 취득부대비·옵션·보조금·잔존가치는 미반영이다. 유지비는 기존 finance.py의 고정 가정과 연비 추정을 사용한다. 부채 잔액은 월 상환액에 독립 추첨한 12~120개월을 곱한 합성 값이며 월 부담 판단에는 월 상환액을 쓴다. 금액·거리는 판단 전에 정수 반올림한다. 선택 차량 월 할부금·유지비는 원 단위 올림하고 월 잔여액은 그 표시값으로 다시 계산해 검증한다.

구매가격상한 0은 미지정이다. 월차량비용한도는 소득-생활지출-기존대출월상환-목표저축-최소월여유자금이다. 선택후월잔여액은 소득-생활지출-기존대출월상환-목표저축-선택차량할부금-선택차량유지비다. 비상자금은 초기 지급 후에도 보존한다.

## 점수·다양성과 평가 분리

기존 통합 비용·크기 점수 80%, 용도별 외부 전장 일치 12%, 선호 연료 일치 8%로 효용을 만든다. 기존 ML 성분은 중립값 0.5로 고정해 모델 예측으로 타깃을 만들지 않는다. 크기 미확인은 크기 일치 점수 0이며 후보 자체를 제외하지 않는다. 용도 목표 전장과 비용 계산은 생성기 코드 및 기존 preferences.py/finance.py를 따른다. 모델별 최고 효용 사양 하나를 남겨 트림 수 편향을 줄이고 softmax 온도 0.055로 반복 추첨한다. 실제 선호 확률이나 시장 점유율은 아니다.

선택확률_만분율은 10000이 100%다. 선택차량점수/최고후보점수는 100점 정수다. 계산·추첨에는 반올림 전 값을 사용한다. 설정 JSON과 원본 카탈로그의 소수점 정밀도는 보존한다.

재무 그룹별 학습/검증/평가 70/10/20 배정 후 가성비중요도·선호크기·용도의 약 20% 조합을 학습·검증에서 보류한다. 평가 재무 그룹에서만 새선호조합평가로 남긴다. 반복 사례는 같은 평가 구간에 둔다. 10052행 중 학습 6748, 검증 904, 새재무상황평가 1960, 새선호조합평가 440이다.

선택 없음 3652행, 동일 입력에서 여러 모델을 선택한 선호 그룹 1474개다. 적격 위반·입력 충돌·재무 그룹 누수·보류 조합 누수는 0건이다. 이는 생성 규칙의 검증이며 실제 모델의 일반화 성능은 아니다.

학습 입력에서는 번호·데이터구분·선택차량 정보·선택 후 비용·확률·점수·후보 수·사유·버전을 제외한다. 선택차량은 가상 타깃이며 선택 없음은 별도로 처리한다. 현 학습기에 자동 연결하거나 재학습하지 않았다.
