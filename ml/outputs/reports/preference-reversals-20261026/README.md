# 명시 선호 역전 검토

규칙 기준선을 유지한 채 보정 sigmoid를 적용한 통합 모델의 변화를 분석했다. 학습 가중치·ML 가중치·선호 가중치·재무 판정·운영 서버는 변경하지 않았다.

기준선은 모든 후보의 ML 기여를0.5로 고정한 결과다. 동일 입력 안에서 이 상수와 분모는 같으므로 규칙 단독 순위와 동일하다. 기존 sigmoid 결과와 비교한 변화와 혼동하지 않는다.

| 항목 | 기존 평가300개 | 추가 평가300개 | 합계600개 |
|---|---:|---:|---:|
| 차량 식별자 기준 상위3 순서 변경 | 69 | 70 | 139 |
| 모델 기준 상위3 순서 변경 | 67 | 70 | 137 |
| 모델 구성 변경 | 27 | 29 | 56 |
| 선호 점수 하락 역전이 있는 사례 | 6 | 3 | 9 |
| 완전 충족 조건을 잃는 역전이 있는 사례 | 5 | 2 | 7 |
| 중요도4~5의 완전 충족 조건을 잃는 사례 | 0 | 0 | 0 |

139개의 차량 식별자 순서 변화 중2개는 모델 순서는 유지된 사양 변경이다. 모델 구성 교체는56개(9.3%)이며, 순서 변경137개(22.8%)와 구분한다. 재무 적격 위반0건, 실제 서비스 순위와 분석 순위의 불일치0건, 기여도 합산 오류0건이다.

## 역전 쌍 분류

상위3 이전·이후 모델 합집합에서 순서가 뒤집힌 서로 다른 모델154쌍을 확인했다. 한 사례에 여러 쌍이 있으므로 사례 수와 합산하지 않는다.

- 명시 평가 항목상 점수가 같거나 낮은 후보가 ML로 올라온 쌍:139개.
- 선호 점수는 낮지만 비용 평가 이점이 있는 후보가 ML로 올라온 쌍:9개.
- 선호 점수는 낮고 비용 평가 이점은 없지만 다른 선호 이점이 있는 쌍:2개.
- 선택한 선호 점수는 유지되며 비용 등의 규칙 순위가 바뀐 나머지:4개.

139쌍의 열세는 측정한 비용·연료·외장 길이·정원 점수에 한정한다. 승차감 등 측정하지 않은 모든 품질까지 열세라는 뜻이 아니다. 현재 데이터에는 그러한 미측정 이점을 입증할 근거도 없다.

전체 역전 쌍에서 비ML 기여 차이의 중앙값은0.0162점, 최대0.3652점이었다. 대부분 근소한 순위 차이를 ML 근사 오차가 뒤집은 것으로 해석할 수 있다. 통계적 유의성이나 소비자 선호 개선을 입증한 값은 아니다.

## X5와 티볼리: 비용 절충 근거는 있으나 최종 역전은 ML이 결정

사례74957. 희망7인승, 정원·중간 크기·가성비 중요도는 모두3이다. 티볼리는 가격이9,823만원 낮지만 월 유지비는7,562원 더 높다. 기본 정원은X5 7명, 티볼리5명이다.

| 티볼리−X5 최종 점수 기여 차이 | 점수 |
|---|---:|
| 비용 | +4.296949 |
| 크기 일치 | +4.050000 |
| 정원 | −8.571429 |
| 비ML 합계 | −0.224480 |
| ML | +0.275122 |
| 최종 합계 | +0.050642 |

규칙만으로 계산하면X5가 앞선다. 비용 절감과 크기 이점은 실제로 존재하므로 모든 절충이 터무니없다고 말할 수는 없다. 하지만 그 이점은 이미 명시 점수에 반영됐으며, 추가 역전을 새로운 취향 발견으로 설명할 수 없다. ML 원본 출력에서X5는127위, 티볼리는7위로 차이가 커져 이 사례를 우선 검토해야 한다.

## EV6와 EV9: 경제적 이점이 없어도 다른 선호 이점은 존재

사례74108. EV9는EV6보다1,837만원 비싸고 월 유지비도24,621원 높으며 희망 크기에서 벗어난다. 반면 정원 평가에는 이점이 있다. 최종 기여 차이는 비용−0.464568, 크기−7.000000, 정원+7.407407로 비ML 합계−0.057161점이고, ML+0.096605점으로 순서가 바뀐다. 비용 이점 없음이라는 분류만으로 모든 절충 근거가 없다고 결론 내리면 안 된다.

## 판단

명시적 선호를 필터로 바꾸거나 가중치를 일괄 변경할 근거는 아직 부족하다. 이번600개에서 중요도4~5의 완전 충족을 깨는 사례는 없었지만, 다른 입력에서도 없다는 보장은 아니다.

현 단계에서는 규칙 기준선을 유지하는 것이 타당하다. 보정 sigmoid의 포화 해결과 추천 품질 개선은 구분한다. ML이 같은 규칙을 학습한 근사치인 만큼, 규칙과 충돌하는 역전은 독립적인 선택·만족도 자료가 생기기 전까지 근사 차이로 기록한다. 비용 절충 근거가 있다는 분류는 사용자 동의나 추천 개선의 판정이 아니다.

cases.csv는600개 사례 요약, reversal_pairs.csv는154쌍의 기여·경제적 차이·원본 순위, details.json은 입력·사양·조건별 손실·점수 상세를 담는다. 미지의 제원은 검증 여부를 별도로 기록했다.

재현: ml 폴더에서 `.venv/Scripts/python.exe -m vehicle_matching.audit_preference_reversals --output outputs/reports/새검토폴더`. 앞선 실험의sample_manifest.json과 고정 보정값을 사용한다.
