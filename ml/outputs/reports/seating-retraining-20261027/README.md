- 학습 입력 148,194개, 후보 1,421,353개, 비교 쌍 1,115,055개.
- validation 입력 26,464개, test 입력 45,695개. 재무 그룹 분할 누수 0건.

- 12 epochs, 선택 epoch 12, validation 고정 최대 50,000쌍 정확도 98.1560%. test는 epoch 선택에 쓰지 않았다.
