# ML 점수 변환 비교 실험

모델: 통합 20261026-refined-v1. 모델 가중치·학습 배열·서비스 ML 가중치1은 변경하지 않았다. 운영 적용 없음.

기존 평가300개(기존150+신규150)를 그대로 재사용했다. 별도 보정300개와 추가 평가300개는 재무 그룹이 서로 겹치지 않으며, 과거 평가 그룹도 제외했다. 보정용으로 예약한 test 그룹은 이후 미사용 평가로 재집계하면 안 된다.

보정 sigmoid는 정답 규칙의 점수를 soft label로 사용해 사례당 동일한 비중으로 맞췄다. c=-0.5850109153, T=28.9080958754. 실제 구매 확률이 아니다. Softmax는 같은 T를 사용한 참고안이며 별도 온도 탐색을 하지 않았다.

순서 변화는 같은 차량의 순서 교환과 상위3 구성 교체를 모두 포함한다. ML 기여 제거는 모든 후보의 ML 값을0.5로 통일해 수행했다. 나머지 가중치와 후보·가격 판정은 실제 CandidateService 그대로다.

두 평가 표본 모두 재무 위반0건, 추천 대수 위반0건. 각300개의 최종9대까지 전부 독립 Decimal 적격 계산으로 확인했다.

후보 중 최하위 출력의 차량 하나를 제거했을 때, 남은 차량 점수의 최대 변화량(사례 평균)은 Min-Max 약0.0292/0.0273, 보정 sigmoid 약0이다. Softmax 약0.0010/0.0014다. Min-Max 양끝0/1은 의도된 값이므로 sigmoid의 포화 동점과 같은 오류로 집계하지 않는다.

## 실제 변화 사례

사례80546: 월소득531.5만원, 생활지출207.6만원, 기존 상환31.8만원, 예금약5.12억원. 휘발유·중간 크기를 각각 중요도5로 선택했다. 기존 상위3은 티볼리/트랙스/아반떼, 보정 후에는 트랙스/코나/셀토스다. 모두 재무 적격이고 휘발유이며, 규칙 점수 차이는 매우 작다. 새 순서가 고객에게 더 좋다는 증거는 아니다.

사례74957: 최소7인승(중요도3), 중간 크기(중요도3), 가성비중요도3. 기존 EV9/X5/트랙스가 보정 후 EV9/트랙스/티볼리로 바뀌었다. 7인승 X5가 빠지고5인승 티볼리가 들어와 정원 절충이 커졌다. 정원은 기존 정책상 상대 조건이므로 재무 위반은 아니지만, 운영 적용 전에 검토할 구체적 사례다.

사례183563: K5/쏘나타/아반떼가 K5/아반떼/쏘나타로 바뀌었다. 쏘나타와 아반떼의 규칙 점수 차이는100점 기준 약0.008점이다. 작은 규칙 차이를 ML 예측 오차가 뒤집은 것으로, 새로운 고객 선호를 발견한 변화로 설명할 수 없다.

## 판단

고정 보정 sigmoid를 다음 검토안으로 권한다. 두 표본에서 포화 없이 순위를 보존하고, 후보 구성 변화에 점수가 의존하지 않았다. Min-Max보다 영향이 완만하지만, 명시적 선호의 절충을 늘리는 사례가 있어 운영 적용이나 가중치 변경은 하지 않았다.

현재 ML은 동일 규칙을 학습한 근사치다. 규칙 단독보다 높은 규칙 일치도를 기대할 수 없으며, 영향력 증가 자체가 개선 지표는 아니다. 사용자 선택/전문가 평가 없이 더 좋은 추천이라고 결론 내리지 않는다.

재현: ml 폴더에서 `.venv/Scripts/python.exe -m vehicle_matching.experiment_score_transforms --output outputs/reports/새실험폴더`.

sample_manifest.json에 보정·평가 그룹, calibration.json에 고정 보정값, report.json에 모든 지표와 모델/학습 배열 해시가 있다. *_cases.csv는 사례별 지표, *_scores.csv는 모든 후보의 원본·변환 점수, changed_examples.json은 상세 사례다.
