# 보완 제원 기반 후보 순위 모델 재학습

`ml/test`에서 실행했다. main, 원본 가격·가구·선택 데이터와 기존 모델은 보존했다.

실행 폴더: `ml/outputs/models/candidate-retrained/20261022-165001-specifications-v1`.

현재 추천 API가 사용하는 사용자–차량 후보 순위 모델을 재학습했다. 기존 306,429행 선택차량 분류 모델의 재학습과는 다르다. 보완된 차량 84개 모델·281개 사양을 사용하고, 독립적으로 생성한 재무·연료 선호 프로필의 적격 후보들을 학습한다. 크기·인원 등 사용자 가중치는 서비스의 최종 통합 점수에서 적용한다.

동일 데이터와 시드 42, 30/60 epoch 후보 선택으로 직전 실행 결과를 재현했다. 이번 반복 학습만으로 정확도가 높아졌다고 주장하지 않는다. NDCG는 명시된 합성 효용에 대한 순위 일치도이며 사용자 만족도 백분율이 아니다.

연비·전비, 전장, 좌석 수 또는 정원 선택지의 빈칸은 없다. K5 LPG 트렌디와 BMW X4 M 스포츠는 정확한 기본 구성의 인증값이 미확정인 참조 연비 표시를 유지한다. 기존 좌석 정보 251개를 새로 전부 독립 검증한 것은 아니다.

모델·전처리 통계는 `model.pt`와 `metadata.json`, 실제 학습 후보는 `catalog.json`, 학습·평가 상세는 `report.json`, 재무 검증은 `audit.json`, 차량별 구성·출처는 `specification-evidence.json`에 보존한다. 관련 Python 테스트 24개가 통과했다.
