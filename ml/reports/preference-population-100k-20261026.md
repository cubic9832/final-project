# 신규 10만 사례 기반 후보 순위 모델

실행 브랜치: ml/test. 기존 306,429행 선택 데이터와 600명 기반 기존 후보 모델을 보존하고 별도의 100,000행을 생성했다.

데이터: `data/households/synthetic/preference-population-100k-20261026-v2`.
모델: `ml/outputs/models/candidate-preferences/20261026-100k-v1`.

학습/검증/평가 입력은 70,000/15,000/15,000행이다. 재무 부적격 및 평가 전용 차량 제외 후 실제 학습에 사용한 후보는 584,184개, 비교 쌍은 301,102개다. 총 100,000행을 모두 학습에 사용했다고 해석하면 안 된다.

## 고정한 정책

일시불 구매, 구매 후 예금으로 월 부족액 최소 12개월 충당, 저축·비상자금·추가 버퍼·할부 입력 0, 연 15,000km, 비용·연료·크기·정원 상대 평가. 비싼 가격에 대한 가점·용도 점수는 없다. 모델은 사용자–후보 쌍을 학습하고 실제 재무 적격 판정은 서비스 규칙이 유지한다.

## 학습 및 평가

29개 입력 특징의 64→32→1 MLP를 pairwise logistic loss와 효용 보조 손실로 학습했다. 12 epoch 중 검증 정확도로 12 epoch를 선택했다. 학습 정답은 현재 규칙의 합성 효용이며 관측된 만족도나 구매 여부가 아니다.

| 지표 | 기존 모델 | 신규 모델 |
|---|---:|---:|
| 모델 단독 NDCG@3 | 0.879942 | 0.925211 |
| 서비스 최종 순위 NDCG@3 | 0.996951 | 0.999998 |
| 학습 제외 17개 모델에서의 단독 NDCG@3 | 0.906195 | 0.961720 |
| 최종 상위 3대 연료 일치율(연료 지정 사례) | 0.830275 | 0.814220 |

위 NDCG는 평가 분할의 서로 다른 재무 그룹 300개 중 적격 후보가 존재한 183개에서 현재 합성 효용과 비교한 값이다. 연료 일치율은 단독 평가 항목으로 소폭 하락했으며 모든 세부 지표가 개선됐다고 주장하지 않는다. 전체 가중 선호 점수에는 크기·정원·비용이 함께 반영된다.

평가 비교 쌍 66,870개의 순서 일치율은 0.986406이다. 검증 효용 절대오차는 마지막 epoch에서 약 0.272이며, 순위가 맞는 것과 점수의 절대값이 정확한 것은 다르다. 출력값을 구매 확률·만족도 또는 정확히 보정된 효용으로 해석하지 않는다. 실제 사용자 평가가 개선됐다는 검증은 하지 않았다.

## 검증

- 전체 100,000행 저장본을 독립 재검사했다. 재무 위반·그룹 누수·평가 전용 차량의 학습 배열 유입·사용자 간 잘못된 비교 0건.
- 기존/신규 모델 각각 1,541개 최종 추천의 재무 조건을 교차 검사했다. 위반 0건.
- 무소득·월 적자·월 여유금 0원·예금 부족의 5개 별도 경계 사례가 기대한 추천/추천 없음 결과를 반환했다.
- 신규 특징은 용도에 따라 바뀌지 않고, 크기·인원·중요도에 따라 바뀐다. 기존 모델과 신규 모델의 로딩 스키마·가중치 해시를 분리했다.
- 검증 입력의 특징 범위 밖 추론에 대한 성능 보장은 없으며, 실제 차량 제원·가격 갱신은 별도 과제다.

전체 기존 테스트 88개 중 84개 통과, 4개 실패다. 실패는 앞선 정책 변경 후 남은 월 여유금 절대 필터 기대 2개, 예금 충당 후처리 기대 1개, 보강 차량 16종과 기존 정원 레지스트리의 ID 집합 불일치 1개다. 이번 학습 작업은 해당 재무 규칙·정원 데이터를 변경하지 않았다. 전체 테스트 통과라고 보고하지 않는다. 로그는 `tmp/preference-population-full-tests.log`다.

상세 값과 학습 이력은 모델 폴더의 `report.json`, `holdout_report.json`, 데이터 폴더의 `validation_report.json`에 있다.

## 로컬 적용

`ml/serve-candidates.ps1`의 기본 실행 경로를 새 모델로 변경하고 8002번 로컬 서버에 적용했다. `/api/v2/recommendation-options`에서 `rankerSchema=candidate-preferences-v3`, 카탈로그 281개를 확인했다. 월소득 200만원·생활지출 220만원·예금 1억원·전기·큰 크기 선호 요청에서 9개 후보와 예금 충당 근거가 반환됐다. 실행 응답은 `tmp/preference-100k-live-response.json`에 저장했다. 기존 모델 경로를 `-Run`에 전달하면 이전 모델로 돌아갈 수 있다.
