# 예산 경계·선호 변경 검증

검증 대상: ml/test의 cash-weighted-budget-v6, candidate-v2 모델 + 확장 카탈로그 265개 사양.

## 범위와 결과

- 재무 시나리오 1,840건, 반환 추천 5,166개.
- 현금 경계 795건: 각 차량 가격에 대해 가용 현금을 가격 -1원, 동일, +1원으로 설정. 비상자금은 별도 유지.
- 월 유지비 경계 795건: 각 차량의 월 유지비에 대해 최소 여유자금 차감 후 월 가용액을 유지비 -1원, 동일, +1원으로 설정.
- 고정 seed 42 무작위 재무·연료·크기·가중치·가격상한 조합 250건.
- 재무 적격 여부를 서비스의 assess 호출과 별도로 가격·비상자금·수입·생활비·기존대출·저축·에너지비·고정유지비로 재계산.
- 구매 가능 금액 초과, 월 여유자금 위반, 중복 모델, 점수 순서 오류, 적격 모델 수 대비 추천 개수 오류: 모두 0건.
- 적격 모델 3개 이상이면 3개 반환, 1~2개면 해당 개수만 반환, 없으면 빈 목록임을 비교.

## 선호 변화

구매 가용 현금 2,000/3,500/5,000/8,000/12,000만 원 × 월소득 250/400/800만 원, 생활비 100만·월대출 10만·저축 30만 원을 고정해 연료 5종과 크기 3종을 비교.

- 30개 비교 묶음 중 26개에서 상위 3개 모델 또는 사양이 달라짐.
- 변화 없는 4개 묶음은 구매 가용 현금 2,000만 원, 월소득 400/800만 원의 연료·크기 비교. 추천은 베뉴·모닝·레이. 현재 목록에서 예산 내 다른 연료 후보가 없고 확보된 후보가 작은 차량에 한정되어 있어 결과가 같음.
- 각 선호를 고정하고 해당 중요도를 1에서 5로 변경: 양쪽 상위 20개에 포함된 동일 사양 중 해당 선호 점수 100점인 후보의 순위 하락은 0건. 전체 카탈로그의 모든 쌍에 대한 수학적 단조성 증명은 아님.

## 실제 서버 확인

127.0.0.1:8002 API에 현금 0/2,000/4,000/6,000만 원 × 연료 5종, 총 20개 요청. 모두 v6 정책 응답. 반환 후보의 현금 및 최소 월 여유자금 위반 0건.

구매 가용 현금 4,000만 원, 월소득 600만 원, 생활비 150만 원, 월대출 20만 원, 저축 100만 원, 최소 월 여유자금 10만 원, 연료 중요도 5:

| 선호 | 추천 |
|---|---|
| 휘발유 | 코나 / 베뉴 / 투싼 |
| 하이브리드 | 코나 Hybrid / 니로 / 투싼 Hybrid |
| 전기 | EV3 / 코나 Hybrid / 코나 |
| LPG | 스포티지 LPG / K5 LPG / 쏘나타 LPG |
| 디젤 | 코나 Hybrid / 코나 / 니로 |

전기는 이 조건에서 예산 내 적격 모델이 부족해 다른 연료 후보로 보충. 디젤도 카탈로그의 후보 부족 때문에 선호가 결과에 나타나지 않는 조건이 있음. 연료 선호는 상대 평가이며 일치 보장 조건이 아님.

## 남은 한계

- 차량 가격과 가정된 유지비 기준에서의 적격성이다. 보험·세금·정비는 공통 추정액이고 연비가 없는 후보는 연료별 가정치를 사용한다. 실제 견적·실제 주행 비용 초과까지 보장하지 않는다.
- 연간 주행거리는 현재 UI의 공통 비교 기준 15,000km. 유지비 경계는 이 기준에서 검사했다.
- 연료 불일치 후보를 보충하는 경우 사용자에게 선호 연료 후보 부족 사유를 더 명확히 안내할 여지가 있다.
- 가격대는 가중치 2의 상대 평가로 변경되어 가용 자금의 80% 아래 차량도 추천될 수 있다.
- 이 검증은 재학습 또는 실제 사용자 만족도 검증이 아니다. 기존 데이터·main 브랜치를 수정하지 않았다.
