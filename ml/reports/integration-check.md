# test 브랜치 ML 통합 검증

2026-10-19에 `feat/data`의 `b3615e7c37e5d5e409c2536020258ef20b25f59a`에서 추천 코드와 기준 데이터를 가져와 검증했다. 원본의 독립 `recommender` 프로젝트를 `ml/`에 배치했으며 데이터 생성기와 웹 화면 변경은 가져오지 않았다.

## 환경과 방법

- Windows, Python 3.14.7, NumPy 2.5.4, PyTorch 2.14.1+cpu.
- CPU로 학습하고 검증 실행 시 OMP_NUM_THREADS와 MKL_NUM_THREADS를 1로 설정했다.
- 국내 10,000명·수입 6,000명의 기준 CSV를 사용했다. 원본 학습·검증·평가 구분을 유지했다.
- 기본 후보 3개, 에포크 상한 30, 배치 256을 사용했다. 전처리는 학습 구간에만 맞추고 모델은 검증 top-3으로 선택했다.

## 확인 결과

- 데이터 조인·누수 방지·학습 전용 전처리·가중치 저장 및 재로딩 등 원본 테스트 14개 통과.
- 두 세그먼트의 CLI 학습 완료. 저장 결과를 다시 읽는 evaluate와 Top 3 predict 실행 성공.
- 기존 `vehicle.predict` 호환 진입점에서도 추천 실행 성공.

| 평가 구간 지표 | 국내차 | 수입차 |

평가 지표는 저장된 모델을 다시 불러와 측정했다. 산출물은 로컬 `ml/outputs/models/{segment}/integration-check/`에 있으며 Git에 포함하지 않는다. 위 수치는 합성 데이터에 대한 통합 실행 확인 결과로 실제 구매 경향이나 구매 자격을 검증하지 않는다.

기존 `epoch-batch-check.md`는 원본 브랜치에서 수행한 별도 실험의 기록이다. 위 수치와 동일한 실험으로 해석하지 않는다.
