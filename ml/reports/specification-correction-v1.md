# 명확한 차량 제원 누락 보완

ml/test에서만 수정. main, 기존 학습 CSV, 학습 모델 가중치·카탈로그 스냅샷은 보존.

281개 사양 점검 결과 연비 206·전장 131·정원 19개 미확인. 공식 확인 가능한 레이 EV 2개와 BMW X5 1개를 보완. 이후 연비 204·전장 129·정원 18개 미확인.

- 레이 EV 라이트·에어 4인승 기본 14인치: 복합 전비 5.1km/kWh, 전장 3595mm. 출처 https://www.kia.com/kr/vehicles/ray-ev/specification
- 월 유지비: 공통 가정 전비 4.5 기준 282223원 → 공식 전비 5.1 기준 270785원 (연 15000km, 전기 단가 350원, 고정 유지비 185000원). 월 11438원 감소. 크기 미확인 중립 평가에서 전장 기반 평가로 변경.
- BMW X5 xDrive30d xLine 7인승: 공식 가격표의 정확한 트림 행으로 정원 7명과 출처 보완. 다른 X5 사양에는 전파하지 않음.
- data/vehicles/specification-correction-v1.json에 변경 전후와 출처 기록. 공식 보완 JSON의 기존 가격·식별 정보는 보존.
- 저장된 학습 카탈로그를 읽는 경우에도 공식 보완값을 추론 시 병합. 모델 파일을 다시 쓰지 않으며 향후 재학습 시에도 동일 값 적용.
- 관련 21개 테스트 통과. 저장된 누락값 보완·유지비 계산·크기 평가·반복 병합·현금 경계를 검증. 실행 중인 8002 서버에도 적용하고 실제 응답의 전비·전장을 확인.

과거 연식 또는 다른 휠 제원을 현재 트림에 일괄 대입하지 않음. 추가 확인되지 않은 제원은 기존 미확인 상태로 유지.
