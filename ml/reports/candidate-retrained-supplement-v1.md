평가 200건 중 133건에 적격 후보가 있고 67건에는 없어 추천 없음. 높은 NDCG는 명시된 합성 기준과의 일치이며 실제 구매·만족도 정확도가 아니다. 정렬 지표는 소폭 개선, 평균 효용 손실은 소폭 악화해 큰 정확도 개선으로 단정할 수 없다. 기존·신규 모두 동일한 현재 현금·유지비·선호 가중 정책으로 비교.

미학습 모델 평가 NDCG@3: 0.999021036. 학습 보류 모델도 공개 카탈로그에 존재하며 새로운 차량의 실제 사용자 라벨 일반화를 뜻하지 않는다.

## 실행 반영

실행 중인 8002 서버의 ML_CANDIDATE_RUN을 신규 경로로 지정. ml/serve-candidates.ps1 기본 Run도 신규 산출물 경로로 지정. 이전 모델로 복귀하려면 -Run experiments/candidate-v2 사용. uvicorn을 직접 실행하면 환경변수 미지정 시 기존 모델이 기본값이므로 실행 스크립트를 사용한다. 신규 모델 산출물은 Git 추적 제외 경로에 있으므로 다른 환경에는 해당 실행 묶음 배포 또는 재학습 필요.

## 수정·검증

재무 값 덧셈 오차로 정상 프로필이 거부되는 문제를 비상자금 차감 후 가용액 비교로 수정. 1원 초과는 그대로 거부. 추가 카탈로그를 학습 저장 후 다시 불러올 때 좌석 보강으로 충돌하는 문제는 불변 차량 식별·가격·연료·출처를 비교해 해결.

관련 비즈니스 테스트 20개 통과. 상세 수치 comparison.json, 학습 정보 report.json, 가중치 model.pt와 metadata.json 참조. 실제 서버 검증 응답은 live_verification.json에 보관.

크기·요소 중요도·가격대는 가중 계산으로 반영하고 재무 한도는 필터로 적용한다. 차량별 연비·보험료 등 미확인 제원을 학습이 해결하지는 않는다. 후속 데이터 정확도 보완은 여전히 필요하다.
