# candidate-v2 실험 결과

2026-10-20, `ml/test` 브랜치. 기존 v1을 교체하지 않은 별도 API 실험이다.

## 변경한 문제 정의

기존은 재무 프로필 → 고정 차량 20종의 보유 라벨이었다. 새 실험은 사용자·차량 특성 → 후보 간 비용·연료 선호 효용의 순위다. 26개 입력 특성, 64·32 은닉층, 단일 점수 출력이며 차량 ID·브랜드·모델명은 특징에 포함하지 않는다. 신규 차량 추가가 출력층 크기를 바꾸지 않는다.

명시적인 재무 조건 검증을 먼저 수행하고 ML은 통과한 후보만 정렬한다. 예산 미달, 충전 불가, 일시불 자금 부족 후보를 ML 점수로 되살리지 않는다. 추천 사유는 실비용 계산값과 선호 일치 사실이다.

## 데이터

- 원본: 저장소의 2026-10-14 공식 자료 자동 추출 CSV 328행.
- 사용: 69개 모델 표기, 231개 가격 사양. 하이브리드·특별판 이름을 포함한다.
- 제외: 97행. 누락 가격·지원 밖 연료·사양 식별 중복이 대상이며 충돌한 식별자의 모든 행을 제외한다.
- 연비 미확인 후보 156개는 null을 유지하고 명시된 연료별 범위로 비용을 추정한다.
- 독립 합성 재무 프로필: 학습 600, 검증 150, 평가 200명.
- 학습 적격 조합 8,070개, 선호 쌍 6,568개. 학습에서 전체 차량 모델 표기 14개를 제외했다.
- 30/60 epoch 후보를 검증 데이터로 비교해 30 epoch를 선택했다.

## 평가

숫자는 실제 만족도나 구매 가능 확률이 아니라 **정의한 합성 효용 순위와의 일치도**다.

| 대상 | ML NDCG@3 | 월 비용 정렬 기준선 | 정답 효용 계산식 기준선 |
| --- | ---: | ---: | ---: |
| 평가 사용자 · 전체 후보 | 0.9951 | 0.7729 | 1.0000 |
| 평가 사용자 · 학습 제외 차량만 | 0.9918 | 0.7835 | 1.0000 |

전체 후보 평가에서 200명 중 121명에게 적격 후보가 있었고 79명은 빈 결과가 맞는 프로필이었다. 121명의 상위 3개에 나타난 모델 표기는 총 27개다. 후보 69종을 모두 같은 빈도로 노출하도록 강제하지 않았다. 이 수치는 모델이 69종을 지원한다는 것과 추천 노출이 69종에 골고루 분포한다는 것이 다름을 보여준다.

선호 가중치를 0.1/0.5로 바꾸면 NDCG@3는 각각 0.9985/0.9897이다. 에너지 단가 +25%, 보험 증가, 금리 스트레스 +5%p 시나리오에서는 0.9984이며 적격 사용자는 118명으로 감소했다. 월소득 300만 미만 구간의 NDCG는 0.9678이지만 적격 사용자가 7명뿐이므로 신뢰할 만한 구간별 실증 결론으로 해석하지 않는다.

원본·카탈로그·가중치·학습 코드 해시, 모든 평가와 학습 이력은 `ml/experiments/candidate-v2/report.json`, `metadata.json`에 있다.

## 검증 및 남은 한계

기존 20개와 신규 11개를 합한 테스트 31개가 통과했다. 신규 테스트는 원리금·일시불 금액 경계, 저축·기존 상환 반영, 스트레스 조건, 미확인 연비, 충전 조건, 적격 후보 없음, 신규 차량 추론, 카탈로그 해시·운영체제 간 줄바꿈 차이, 실제 모델을 사용하는 API 오류 계약을 검증한다. 8002 서버 실제 HTTP 요청도 검증했다.

새 구조는 후보 수의 하드코딩과 불명확한 목표를 해결하는 실험 기반이다. 합성 데이터 편향과 현실 타당성은 해결됐다고 주장하지 않는다. 명시한 정답 계산식을 직접 사용하는 방식의 점수가 더 높으며, ML 자체의 사업적 우월성을 입증한 것도 아니다. 실제 사용자의 선호·구매 후 지출·만족도 데이터로 학습·평가 목표를 바꾸는 후속 검증이 필요하다.
