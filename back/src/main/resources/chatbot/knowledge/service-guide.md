# CreditCompass 서비스 안내

## 서비스 이용 안내 · 주요 기능 · 처음 이용하는 순서
CreditComPass는 첫 차 취향을 살펴보고 차량 정보와 비교 기능을 이용할 수 있는 서비스다. 주요 메뉴는 재무 진단(/financial), 차량 찾기(/search), 차량 비교(/vehicles/compare), 로그인 후 이용하는 첫 차 취향 테스트(/taste-test)다.
처음 이용한다면 차량 찾기에서 관심 있는 차를 살펴보고 비교 기능을 이용할 수 있다. 본인의 취향부터 알고 싶다면 로그인 후 마이페이지의 취향 테스트로 시작할 수 있다. 재무 조건을 기준으로 살펴보고 싶으면 재무 진단 메뉴를 이용한다. 모든 사용자가 한 가지 순서를 반드시 따라야 하는 것은 아니다.
콤파의 서비스 이용 카테고리는 이용 방법을, 차종 도감은 MPV·SUV·세단 같은 차체 분류를, 자동차 용어는 하이브리드·복합연비 같은 표현을 안내한다. 화면의 파란색 용어를 누르면 관련 설명을 콤파에 물어볼 수 있다.

## 첫 차 취향 테스트
첫 차 취향 테스트는 질문에 대한 답변을 바탕으로 자동차 취향 유형과 대표 차량을 확인하는 기능입니다. 로그인한 회원은 /taste-test에서 시작할 수 있으며 마이페이지에서도 진입할 수 있습니다.
결과 화면에서 저장을 눌러야 회원별 현재 취향이 저장됩니다. 테스트를 시작하거나 결과만 확인하는 것으로는 기존 취향이 바뀌지 않습니다. 재검사 결과를 저장할 때 기존 결과를 덮어쓸지 확인합니다.

## 차량 찾기와 비교
비회원도 차량을 조회할 수 있습니다. 차량 비교 메뉴에서 차량 선택과 비교 흐름을 이용할 수 있습니다. 이 안내 문서에는 개별 차량의 최신 가격, 재고, 금융 조건이 없으므로 해당 정보는 차량 화면에서 확인해야 합니다.

## 회원가입과 이메일 인증
회원가입은 이메일 인증을 거칩니다. 인증 코드는 5분 안에 입력해야 합니다. 실제 메일 발송 설정이 없는 로컬 개발 환경에서는 인증 메일 대신 Spring 로그의 DEV-MAIL 항목에 인증 코드가 표시됩니다.

## 챗봇 이용 안내
챗봇은 로그인한 회원만 이용하며 서비스 이용·자동차와 관련 금융 용어를 설명합니다. 등록된 안내 자료를 검색하고, OpenAI 사용 시에는 로그인한 회원의 최근 진단 요약과 현재 취향도 참고할 수 있습니다. Gemini에는 개인 결과를 자동 첨부하지 않습니다. 회원 정보나 결과를 변경하는 기능은 없습니다.
직접 입력하는 AI 질문은 500자, 회원별 한국 시간 하루 30회까지입니다. 추천 질문 버튼과 화면의 용어 설명은 등록된 고정 답변으로 안내하며 외부 AI 호출과 일일 질문 횟수를 사용하지 않습니다. 외부 AI 호출을 시도한 요청은 실패하더라도 횟수에 포함됩니다. 대화 삭제로 사용 횟수가 복구되지는 않습니다. 대화는 회원별 최근 10개 메시지를 서버 메모리에 보관하여 새로고침 뒤 복원되며, 서버 재시작 시 대화와 사용량이 초기화됩니다. 개인정보는 전송과 기록 전에 가리지만 완벽하게 감지하지 못하므로 입력하지 않아야 합니다.
